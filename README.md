
# enoTone — Android

**enoTone** — нативный Android-аудиоплеер на Kotlin и Jetpack Compose для личной музыки из Cloud.Mail.ru через HTTPS WebDAV. Основная проверенная структура — плоская папка `/AllMusic`. Приложение не зависит от Google Play Services/Firebase; старый Flutter-прототип не используется.

**Срез: 18 ноября 2026, `main` `febbea33e5aa68064792fce9c73d1a6a48f36df3`, версия приложения `0.6.2`.** Проект находится в разработке, это не публичный релиз. В `main` слиты D3.5 (#169), D5 B (#167), исправления D5 (#174, #176), R-A7 (#180), F-02 (#185), D5-C (#183), DOC-01 (#187), переход восстановленного плеера (#189), F-01 (#194), F-03 (#196), R-A1 (#198) и Q1 (#199), F-04 (#206). Оперативные факты и нерешённые вопросы: [STATUS](docs/STATUS.md), [KNOWN_ISSUES](docs/KNOWN_ISSUES.md) и [ROADMAP](docs/ROADMAP.md).

## Реализовано в `main`

- WebDAV: проверка входа, `PROPFIND Depth: 1`, `Range GET` и инкрементальный импорт/обновление медиатеки. Метаданные MP3/FLAC индексируются в фоне; Room хранит локальный каталог. Проверенная ранее библиотека включала 3590 файлов — это **исторический результат устройства**, не число файлов на текущем запуске.
- Медиатека: «Домой», «Песни», «Альбомы», «Артисты» и «Авторы альбомов», подробности альбомов и исполнителей, поиск по подготовленным в памяти ключам с русской сортировкой. **FTS4 отменён** ([ADR-0091](docs/DECISIONS/ADR-0091-no-fts-memory-search.md)); текущая схема — **Room v7**. Плейлисты и «Избранное» подготовлены на уровне данных, но пользовательского редактора плейлистов нет.
- Media3/MediaSessionService: воспроизведение в фоне, уведомление, очередь из контекста медиатеки, repeat/shuffle, seek, сохранение очереди и позиции, ручные действия «Играть следующей» / «В конец очереди». Временный аудиокэш и предзагрузка следующего трека не являются постоянным офлайн-хранилищем.
- Обложки: один постоянный WebP-мастер до 1200 px в приватном `filesDir`, общая обложка альбома на экранах, два режима загрузки и ручная очистка ([ADR-0067](docs/DECISIONS/ADR-0067-permanent-album-artwork.md)).
- Android v2: темы «Графит»/«Фарфор», компоненты и навигация с нижней панелью и мини-плеером; единый fade-through страниц и отдельная вертикальная шторка полного плеера (D3.5, [ADR-0095](docs/DECISIONS/ADR-0095-simple-motion.md)). Индикация буфера и следующего трека добавлена D5 B; D5-C (#183) добавил акцентный цвет исполнителя, строку «Альбом · год», общий лист «⋮», круглую кнопку паузы/воспроизведения, выверенные иконки и единый Snackbar поверх плеера. Счётчик `N / M` сохранён решением владельца.
- Постоянный вход хранится с помощью Android Keystore (AES-GCM); «Выйти» удаляет данные аккаунта по утверждённому порядку. Есть подписанный канал **Stable Preview**, рассчитанный на обновление поверх установленной версии без потери данных.

## Что ещё не готово или не подтверждено

Вне текущей реализации: UI плейлистов, редактирование очереди отдельным экраном, дополнительные музыкальные источники SAF, постоянный офлайн-аудиокэш, интерфейсы ИИ, полноценная поддержка тегов других форматов. Открыты задачи по сетевому слою, воспроизведению и покрытию MP3/ID3 ([#182](https://github.com/metravolokos/enoTone-android/issues/182)); подробнее — [KNOWN_ISSUES](docs/KNOWN_ISSUES.md).

**Принятие владельца 2026-11-17:** владелец общим сообщением подтвердил принятые к этой дате PR, ранее ожидавшие Huawei, в том числе D3.5, D5 и поиск. Перечня сценариев, сборок и измерений (в частности, задержки поиска ≤20 мс) нет: **поимённый Huawei PASS не устанавливается**, [SCENARIOS](docs/SCENARIOS.md) не переписывается. Изменения D5-C (#183), слитые после этого подтверждения, ещё требуют проверки на телефоне: ACT-01/03, видимость Snackbar очереди над плеером/доком, открытие «Настроек» без мигания, DES-01/O-08 в двух темах и нижний ряд «Сейчас играет» (вертикальная раскладка принята как есть).

## Сборка и проверка

Требуются **JDK 17, Android SDK 36**; `minSdk 26`, `targetSdk 36`. Проект — Gradle Kotlin DSL, подключённые модули перечислены в [ARCHITECTURE](docs/ARCHITECTURE.md).

```bash
./gradlew :app:assembleDebug
./gradlew testDebugUnitTest lintDebug detekt
python3 design/tools/sync_android.py --check
```

На Windows используйте `gradlew.bat`. Полный набор проверок и известные ограничения Windows — в [TESTING](docs/TESTING.md).

**Важно для установки:** `debug` получает отдельный идентификатор `app.enotone.android.preview.rN` и эфемерную подпись; он **не обновляет** Stable Preview. Канал `app.enotone.android.preview` подписывается постоянным секретным ключом CI. Не удаляйте установленную Stable Preview ради тестовой сборки: Room и пользовательские данные должны сохраняться. Учётные данные, имена файлов и личные пути нельзя публиковать в отчётах.
