## Обоснование отмены

Запись тегов в облачные файлы требует скачивания файла целиком (частичная запись
в WebDAV нестандартна: альбом ~100 МБ скачать и ~100 МБ загрузить), временного
файла с проверкой и `MOVE` по `If-Match`, библиотеки записи тегов для MP3/FLAC/M4A
с риском для единственной копии музыки владельца, нового экрана редактора
(`design-needed`) и отдельной модели правок поверх тегов файла.

Для пользователя, который правит теги в облаке сам, стоимость и риск не оправданы.
Функционал выходит за рамки «простого офлайн-плеера личной музыки».
