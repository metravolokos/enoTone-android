# ROADMAP — enoTone Android

Для каждой стадии: CI debug build/tests/lint/GMS gate зелёный, APK в артефактах, документы и CHANGELOG обновлены, ручная проверка описана.

- **M0 (в работе):** структура Gradle-модулей, версия SDK, CI без GMS, mock WebDAV, диагностический экран PROPFIND/Range/ETag/Depth и отчёт для владельца.
- M1: WebDAV indexing, Room, теги, инкрементальная синхронизация и прогресс.
- M2: Треки/Альбомы/Артисты, FTS, обложки 192/512/1320.
- M3: Media3, WebDAV DataSource, media session, foreground playback, медиа-кнопки, аудиофокус.
- M4: очередь, shuffle, repeat, сохранение состояния.
- M5: временный полный кэш текущего и следующего трека с прелоадом.
- M6: производительность, доступность, локализация, релиз.
- M7: UI плейлистов (будущее).
- M8: ИИ-подключение (будущее, только opt-in).
- M9: офлайн-загрузка и DocumentsProvider (будущее).

**Стоп после M0** до подтверждения владельца и теста WebDAV на реальном устройстве.
