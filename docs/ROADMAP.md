# ROADMAP — enoTone Android

Критерии для каждого этапа: зелёный CI на точном HEAD (build/tests/lint/GMS gate), debug APK в артефактах, обновлённые документы/CHANGELOG, инструкция ручной проверки.

- **M0 — техническая проверка выполнена, ожидает приёмки:** Gradle-модули, CI без GMS, mock WebDAV, диагностика PROPFIND/Range/ETag/Depth. CI #10 зелёный и реальное устройство проверено 2026-11-08; замечания по `Depth: infinity` зафиксированы в CLOUD_MAILRU_WEBDAV.md. До merge остаются лицензия/решение владельца, актуальный зелёный CI после документации.
- **M1:** WebDAV indexing `Depth: 1`, разбор XML Multi-Status, Room, теги, инкрементальная синхронизация и прогресс.
- M2: Треки/Альбомы/Артисты, FTS, обложки 192/512/1320.
- M3: Media3, WebDAV DataSource, media session, foreground playback, медиа-кнопки, аудиофокус.
- M4: очередь, shuffle, repeat, сохранение состояния.
- M5: временный полный кэш текущего и следующего трека с прелоадом.
- M6: производительность, доступность, локализация, релиз.
- M7: UI плейлистов (будущее).
- M8: ИИ-подключение (будущее, только opt-in).
- M9: офлайн-загрузка и DocumentsProvider (будущее).
