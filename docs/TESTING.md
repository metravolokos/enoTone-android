## FlatWebDavListingParser unit tests
- Только элементы самой /AllMusic, не корневая папка; неожиданные подпапки и вложенные файлы пропускать.
- DAV namespace и успешный propstat 2xx, отбрасывать 404; читать ETag, размер, mtime.
- NFC из NFD, decode percent encoded UTF-8, корректно сохранить плюс в имени.
- Запрет внешних URI, URL с выходом из пути, %2F внутри имени, DTD/XXE и слишком длинных полей; ошибки не должны содержать приватных значений.
- Обработка дублей. Никаких реальных credential или имён файлов из облака в тестовых фикстурах.

После unit tests подключение парсера к реальному WebDAV и запись Room будут отдельными шагами; считать M1 незавершённым.
