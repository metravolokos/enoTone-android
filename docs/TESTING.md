# M1 — проверка локального импорта

## Автоматические проверки
- Основные Android build, unit tests для WebDAV и snapshot planner, lint, strict GMS gate, schema v1 check — обязательны на точном HEAD.
- UI добавляет связи с Room; автоматические тесты бизнес-логики уже есть, но реальное открытие Room на устройстве требует ручного/инструментального теста.

## Ручная проверка Huawei после успешного APK
1. Установить APK, открыть экран и ввести e-mail и пароль внешнего приложения только на устройстве.
2. Нажать **«Сохранить список музыки на устройстве»**. Ожидаются около 3590 записей, без личных названий в отчёте.
3. Нажать **«Проверить сохранённый список (без сети)»**; число должно совпадать.
4. Полностью закрыть/перезапустить приложение, **не подключаться к облаку**, ввести только e-mail (пароль оставить пустым), нажать локальную проверку.
5. Повторить импорт, проверить, что число не удваивается; новые/изменённые/неизменные счётчики должны иметь разумные значения.

Присылать только счётчики или текст обезличенной ошибки. Нельзя присылать пароль, имена треков, ETag, скриншоты с введённым паролем. Удалять/сбрасывать существующую БД приложение не должно.

## Границы теста
- Это диагностический импорт имён файлов и версий, **не** аудиотеги и не проигрывание.
- Локальное хранение путей в приватной Room БД не равно сохранению пароля: пароль нигде не записывается.

## Реальный результат (Huawei, 2026-11-08)
Кнопка проверки локального списка показала **3590** записей с сообщением «Облако не запрашивалось». Это проверка чтения Room, а не чтения аудиотегов. Личные снимки экрана в Git не переносить.

## Начальный срез аудиотегов
- JVM unit tests: Unicode NFC (включая кириллицу), fallback title из имени файла, отсутствие выдуманных artist/album, управляющие символы и лимиты.
- В текущем PR MediaMetadataRetriever не получает аудиопоток из Cloud.Mail.ru. Нельзя выдавать этот тест за подтверждение поддержки форматов.
- Следующий тест на Huawei — один добровольно выбранный реальный файл через строго ограниченный WebDAV Range `MediaDataSource` (ещё не реализован).
