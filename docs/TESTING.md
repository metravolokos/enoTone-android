# TESTING — как проверяется enoTone

> Текущая стратегия и **открытые** ручные проверки. Журнал всех аппаратных проверок 2026-11-08…11 (Huawei Preview #36…#301 с числами) — [archive/TESTING_JOURNAL_2026-11-08_11.md](archive/TESTING_JOURNAL_2026-11-08_11.md). Действующие решения — [CURRENT_DECISIONS](CURRENT_DECISIONS.md).

## 1. Автоматические проверки (CI, `.github/workflows/ci.yml`)

| Шаг | Что проверяет |
|---|---|
| `python3 -m unittest discover -s tools -p 'test_*.py'` | mock WebDAV (`tools/test_mock_webdav.py`) и «контрактные» тесты исходников (см. ниже) |
| Gradle Wrapper validation | `gradle-wrapper.jar` не подменён |
| `gradle :app:assembleDebug testDebugUnitTest lintDebug` | сборка, JUnit и Android Lint **во всех модулях** |
| `gradle detekt` | статический анализ Kotlin + правила ktlint; **пока только отчёт** (артефакт `detekt-reports`), CI не блокирует — [ADR-0076](DECISIONS/ADR-0076-quality-tooling.md) |
| `:app:compileStablePreviewKotlin` | компиляция варианта Stable Preview без секретов |
| Room schema | экспортированные схемы v1–v4 совпадают с закоммиченными |
| `tools/check_no_gms.py` | дерево зависимостей и байты APK не содержат `com.google.android.gms`, `com.google.firebase`, `com.google.android.play` |
| Stable Preview (только `main`) | подпись постоянным ключом и совпадение отпечатка сертификата |

Локально (нужны JDK 17+ и Android SDK 36 в `ANDROID_HOME`; Gradle скачивает wrapper):

```bash
python3 -m unittest discover -s tools -p 'test_*.py' -v
./gradlew :app:assembleDebug testDebugUnitTest lintDebug detekt
```

Отчёты detekt: `<модуль>/build/reports/detekt/`.

Mock-сервер: `python3 tools/mock_webdav.py` (только HTTP на loopback, только для тестов); синтетические WAV с кириллическими NFC/NFD-именами — `python3 tools/generate_fixtures.py <каталог>`.

### Известный долг тестов

- `tools/test_*_contract.py` (кроме `test_mock_webdav.py`) читают `.kt`/`.md` и проверяют наличие строк. Они **не проверяют поведение** и ломаются при любом рефакторинге. Новые такие тесты **не добавлять**; замена — M6-0/5 ([ADR-0074](DECISIONS/ADR-0074-m6-0-tech-debt-plan.md)).
- В Draft #92 добавлены поведенческие JVM/JUnit-тесты `:app` (`LibraryViewModel`) и чистого преобразования `:data:library`. Room DAO/миграции (`MigrationTestHelper`) и Compose UI-тесты пока отсутствуют.

## 2. Ручная проверка на Huawei

Правила: устанавливать **подписанную** `app.enotone.android.preview` поверх предыдущей, не удалять приложение и данные; **не** запускать полную переиндексацию 3590 файлов ради UI-проверки; в Git и issue — только обезличенные числа и коды, без имён файлов, путей, ETag и учётных данных.

Последнее базовое принятие — Stable Preview **#301**, ответ владельца «Работает». Он **не** означает PASS для пунктов ниже.

### Открытые проверки

1. **Graphite Material 3 (ADR-0073, Stable Preview из CI #347):** светлая/тёмная/системная тема, нижняя навигация, мини-плеер, Now Playing (seek, shuffle/repeat; регулятора громкости нет — O-12), страница альбома, длинные названия, TalkBack-подписи.
2. **Одна обложка альбома** на всех экранах (сетка, детали, строки треков, мини-плеер, Now Playing); «Неизвестный альбом» не объединяет чужие картинки.
3. **Offline обложек:** показать альбом онлайн → закрыть приложение → выключить сеть → открыть: картинка из `filesDir`, без нового GET.
4. **ON_DEMAND:** не загружает невидимое; повторный показ — без GET.
5. **AUTO_AFTER_IMPORT:** отдельная фоновая подготовка, прогресс, Pause/Stop, checkpoint; не мешает воспроизведению.
6. **Ручная очистка обложек:** размер в Настройках, подтверждение, автоочистки нет.
7. **Переиндексация обновлённого файла** с прежним ETag сбрасывает ссылки на обложку, общий WebP не удаляется.
8. **M6-0/2 — воспроизведение с выключенным экраном:** 20+ минут по Wi-Fi, не менее 5 автопереходов между треками, без обрывов. Затем открыть приложение: медиатека, импорт/обновление и фоновая индексация работают как раньше (общая база данных).
9. **M6-0/3 — сохранение очереди (ожидает Huawei):** запустить альбом, перейти к 3-му треку, перемотать на середину, включить shuffle и repeat all. Смахнуть приложение из недавних → открыть снова: мини-плеер показывает тот же трек на паузе; Play продолжает с сохранённой позиции, Next идёт в том же shuffle-порядке, repeat all сохранён. Повторить, но вместо смахивания выбрать Android Настройки → «Остановить»; результат тот же. Удалить сохранённый вход в Настройках → перезапустить: очередь не восстанавливается, ошибок нет. **До первого Play:** убедиться, что счётчики playback GET/байтов диагностики не растут. В технической диагностике проверить значение «Восстановление Media3 (главный поток)» для полной очереди 3590: цель ≤50 мс, интерфейс не должен зависать; loadedQueueSources увеличивается порциями. При внезапном убийстве процесса позиция может отличаться до очередного 12-секундного snapshot; проверять фактическую точность и не заявлять PASS без отчёта.

10. **M6-0/4a — регрессионный smoke после Draft PR #92 и merge по команде владельца:** установить подписанную Stable Preview поверх предыдущей, без удаления данных. Открыть все четыре страницы — Треки, Альбомы, Исполнители, Исполнители альбомов; убедиться, что 3590 треков и обложки на месте. Поиск по кириллице даёт прежний результат, сброс поиска возвращает весь список. Запустить трек: пауза/Play, Next/Previous, shuffle/repeat, мини-плеер, Now Playing. Свернуть/развернуть приложение и повернуть устройство (ориентация Activity пока зафиксирована portrait) — состояние не сбрасывается и музыка не прерывается. Повторить сценарий M6-0/3 (сохранённая очередь и позиция, отсутствие GET до Play); из меню альбома явно подтвердить обновление тегов не более 10 файлов и проверить локальную перезагрузку. Не запускать полную индексацию. **Ожидает отчёта владельца, PASS не выставлен.**

11. **Дополнение к M6-0/4a — Huawei, восстановление и общий мини-плеер (Draft #92, НЕ PASS):** сохранить вход добровольно; запустить альбом, shuffle + repeat all, несколько переключений, пауза → смахнуть приложение из недавних → открыть **«Домой»** без автоматического перехода в медиатеку. Мини-плеер показывает прежний трек на паузе. Перейти по очереди на **Треки, Альбомы, Исполнители, Исполнители альбомов, Настройки**: мини-плеер остаётся доступен, Now Playing открывается и закрывается, Play/Next работают из Home/Настроек, порядок shuffle и repeat сохранены. До первого Play сетевые GET не растут. В **Настройки → технические инструменты** переписать только строку `Очередь: <код> · чтение <код> · layout <число> · position <число> · ошибок <число> (<тип исключения>)` — без идентификаторов, названий файлов, путей и паролей. Повторить после системной команды Android **«Остановить»** вместо смахивания. Повторить без сохранённого входа: автоматического восстановления быть не должно. Для смахивания и «Остановить» требуется раздельный PASS/FAIL после проверки на устройстве.

12. **Исправления после Huawei 2026-11-12:** (а) восстановить очередь (пауза → смахнуть → открыть) и открыть «Сейчас играет» **до** Play: шкала стоит на сохранённой позиции, справа — оставшееся время, а не «--:--» (для очереди, сохранённой этой сборкой; у старого сохранения длительности нет). (б) Прокрутить список треков далеко вниз → запустить трек → открыть «Сейчас играет» → назад: список на той же позиции. То же для сетки альбомов. (в) На «Сейчас играет» регулятора громкости нет; системные кнопки громкости работают.

Результат 2026-11-12 (владелец, сборка из `9e20bce`): восстановление очереди после смахивания на паузе — **PASS** (продолжает с места остановки); найдены дефекты (а) и (б), исправлены этим PR.
