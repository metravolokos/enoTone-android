## Работает и подтверждено на Huawei

- **Принята версия 0.6.1** (`0.6.1-preview.446`, метка `v0.6.1`): вход сохраняется автоматически, кнопка «Выйти» с подтверждением и числом треков, «Отмена» ничего не удаляет (Б-1). Реальный выход (Б-2) не проверялся.
- **Принята версия 0.6.0** (`0.6.0-preview.429`, метка `v0.6.0`): шкала восстановленного трека, возврат на позицию списка, без регулятора громкости, мини-плеер на «Домой», иконка v2.0, номер версии в Настройках.
- **Восстановление очереди** после смахивания на паузе: продолжает с места остановки (2026-11-12, после #92).
- WebDAV Cloud.Mail.ru: PROPFIND 207, Range 206 с нестандартным `Content-Range: bytes=…`.
- Импорт/обновление `/AllMusic` одним действием, теги MP3/FLAC (массовая проверка — 3590/3590; сейчас в библиотеке владельца 3647 треков), Room v4, фоновая индексация с checkpoint и Pause/Stop.
- Медиатека: Треки, Альбомы (с «Неизвестным альбомом»), Исполнители, Исполнители альбомов, локальный поиск, настройки видимости страниц.
- Воспроизведение Media3 в MediaSessionService: фон, уведомление, экран блокировки, Next/Previous, shuffle/repeat, перемотка, временный кэш текущего + следующего трека.
- Постоянные обложки: мастер до 1200 px в `filesDir/enotone-artwork-v2`, режимы ON_DEMAND / AUTO_AFTER_IMPORT.
- Обновление Stable Preview поверх предыдущей без потери Room.
- Детальные сценарии обложек (offline / нулевые GET / автообход / очистка, TESTING п. 2–7) с Stable Preview #301 отдельно **не** подтверждены.
