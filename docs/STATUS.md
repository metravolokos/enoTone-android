- **Уточнение владельца от 2026-11-08:** `/AllMusic` — плоская медиатека без вложенных папок. Для M1 требуется один `PROPFIND Depth: 1` без рекурсии. Исполнитель и альбом определяются по тегам, а не по расположению файла.
- Реальный `PROPFIND /` — HTTP 207, 539 мс; `PROPFIND /AllMusic` — HTTP 207, 1536 мс.
- Реальный `GET Range: bytes=0-0` — HTTP 206, 477 мс; `ETag` у GET **есть**. Это проверка диапазона, не тест проигрывания.
- `PROPFIND Depth: infinity` не получил HTTP-кода за 15011 мс (предел запроса 15 с); не считать поддержанным и не объявлять запрещённым. Для M1 рекомендован `Depth: 1`.
- `Accept-Ranges` в ответах не обнаружен: это не отменяет наблюдённый HTTP 206. `ETag` в **HTTP-заголовке** `PROPFIND` отсутствует; `getetag` **в XML** не проверен.

Подробный протокол: `docs/CLOUD_MAILRU_WEBDAV.md`.
