- M0: Cloud.Mail.ru PROPFIND 207 и Range 206 на Huawei, GMS-free CI.
- M1: плоская /AllMusic содержит **3590** аудиофайлов, 0 пропущенных; на Huawei диагностическая локальная Room вернула **3590** без нового запроса к облаку.
- PR #1–7 объединены с main после зелёных CI. PR #7: системный MediaMetadataRetriever adapter и нормализация тегов; реальные теги ещё не тестировались.

## Текущий PR — один файл
- WebDAV Range reader: 64-КиБ блок, 8 МиБ/128 GET, только 206 с точным Content-Range, без redirect и без GMS.
- Диагностическая кнопка запускает чтение тегов **одного** файла из сохранённой Room, при пустом тестовом пути — один файл автоматически (MP3 в приоритете). Не сохраняет/не отображает значения тегов.
- MockWebServer тесты и ADR-0018. **Ожидается зелёный CI на точном HEAD**, после этого ручная проверка одного файла на Huawei.
