- Индексация: пауза/продолжение, остановка, выключенный экран (IDX-01..03) — нужен импорт сотен новых файлов; пока только JUnit.
- Обложки: offline, режимы, очистка (ART-02..05) — базовое принятие Stable Preview #301 («Работает») их не подтверждает; выход Б-2 (OUT-02) — только по решению владельца.
- Принудительная остановка и перезагрузка (REST-05, REST-07), смена PIN (ACC-05).
- Graphite Material 3 (ADR-0073) — визуальная приёмка не получена; будет заменена дизайном v2 (D2).
