# STATUS — 2026-11-08

## Подтверждено
- M0: Cloud.Mail.ru PROPFIND 207 и Range 206 на Huawei, GMS-free CI.
- M1: плоская /AllMusic содержит **3590** аудиофайлов, 0 пропущенных; на Huawei диагностическая локальная Room вернула **3590** без нового запроса к облаку.
- PR #1–7 объединены с main после зелёных CI. PR #7: системный MediaMetadataRetriever adapter и нормализация тегов; реальные теги ещё не тестировались.

## Текущий PR — один файл
- WebDAV Range reader: 64-КиБ блок, 8 МиБ/128 GET, только 206 с точным Content-Range, без redirect и без GMS.
- Диагностическая кнопка запускает чтение тегов **одного** файла из сохранённой Room, при пустом тестовом пути — один файл автоматически (MP3 в приоритете). Не сохраняет/не отображает значения тегов.
- MockWebServer тесты и ADR-0018. **Ожидается зелёный CI на точном HEAD**, после этого ручная проверка одного файла на Huawei.

## Ещё не готово
- Массовое извлечение тегов, запись тегов в Room, поиск/альбомы/исполнители, playback, постоянный аудиокэш. Не запускать загрузку всех 3590 файлов.
- Лицензия исходников, Gradle Wrapper, реальные тесты форматов, инструментальные тесты БД.

## Ошибка обновления APK (Huawei, 2026-11-08)
Владелец сообщил, что APK CI #33 нельзя установить поверх старого: **сертификаты подписей не совпадают**. Корень причины: автоматически генерируемый `~/.android/debug.keystore` на каждом временном CI runner. Старая Room с 3590 файлами **должна быть сохранена**.
Новый Draft PR создаёт отдельное debug-приложение `app.enotone.android.preview.r<run_number>` («enoTone Preview #<run_number>»), сохраняет прежний пакет и изменяет имя артефакта. **До зелёного CI и ручного теста установка Preview не подтверждена.**
Стабильного закрытого ключа подписи пока нет; он потребуется через GitHub Secrets до распространения повторных обновлений Preview. См. ADR-0019. Не предлагать удалять старую версию.
