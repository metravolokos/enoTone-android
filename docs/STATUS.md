## Реализовано в `main`

- **Данные:** WebDAV Cloud.Mail.ru с плоской `/AllMusic`, локальный Room **v7**, MP3/FLAC-теги, инкрементальная фоновая индексация, обложки WebP до 1200 px в постоянном `filesDir`. FTS4 убран в #143 по [ADR-0091](DECISIONS/ADR-0091-no-fts-memory-search.md); поиск — по подготовленным ключам в памяти, русская сортировка и правила ё/е сохранены.
- **Плеер и очередь:** Media3 + MediaSessionService, уведомление, repeat/shuffle, seek, временный кэш, предзагрузка следующего трека, сохранение очереди/позиции, действия «Играть следующей» / «В конец очереди» (#134 и #145). Room-модель плейлистов есть, UI плейлистов нет.
- **Android v2:** D1/D2, D3–D3.3, D4a/D4b, D3.5 (#169), D5 B (#167), исправления #174 и #176 слиты. D3.5 заменил прежний slide/shared-artwork на один fade-through страниц и вертикальную шторку «Сейчас играет» ([ADR-0095](DECISIONS/ADR-0095-simple-motion.md)). Буфер и состояние следующего трека есть в `main`; доводка экранного соответствия по артборду — только в Draft #183.
- **Качество:** Robolectric/Compose UI/Roborazzi, detekt/ktlint, проверка ADR, GMS-gate, проверка дизайн-ресурсов; канонический LF закреплён в `.gitattributes` (#185, [ADR-0096](DECISIONS/ADR-0096-canonical-line-endings.md)). R-A7 (#180) исправил ряд ошибок парсера тегов; остаточное покрытие — [#182](https://github.com/metravolokos/enoTone-android/issues/182).
