**Статус:** рабочая Stable Preview / действующий Android MVP в развитии, **не полный релиз и не выполнение всего первоначального ТЗ**. Исторические записи в STATUS/CHANGELOG/ADR не стираются.

## Изменения исходных требований, принятые владельцем

1. Название продукта — **enoTone**, не историческое AllMusic; `/AllMusic` остаётся папкой.
2. Каталог **плоский**: `PROPFIND Depth: 1`, без рекурсивного обхода.
3. **Никакого Wi-Fi-only:** индексирование возможно в любой сети, только по инициативе пользователя; должно продолжаться при свёрнутом приложении и блокировке экрана. Для этого выбран dataSync Foreground Service вместо начального WorkManager.
4. **Исполнители** и **Исполнители альбомов** — отдельные страницы; нужен **Неизвестный альбом**; каждую страницу можно скрыть, сохранив минимум одну.
5. Другие аудиоформаты отложены до появления реальных тестовых файлов; на данном устройстве содержатся FLAC и несколько MP3.
6. Android пока использует стандартные цвета Material 3. Фирменные иллюстрации/палитру из дизайн-репозитория не внедрять без отдельного утверждения именно для Android.

## Практический порядок дальнейшей разработки

**Сначала качество пользовательского опыта:** проверить, не загораживают ли остающиеся диагностические элементы списки, убедиться в устойчивом входе, переключении страниц и мини-плеере. Затем — обложки и расширенный поиск/сортировка, сохранение очереди и позиции после завершения процесса, аудиофокус и сетевые сценарии, тесты производительности и доступности. После этого отдельно согласовать фирменный дизайн, вопросы лицензии и релизной сборки. Дополнительные форматы — только с воспроизводимыми примерами. Не проводить полную переиндексацию только ради проверки UI.

## Документы и правило обновления

`README.md` — краткая внешняя витрина; этот файл — **срез фактов на конкретную дату**; `ROADMAP.md` — актуальные следующие задачи; `STATUS.md`, `TESTING.md`, `CHANGELOG.md`, ADR — **неизменяемая историческая база доказательств** с новыми дополнениями в конце. Слово «Draft» в историческом абзаце означает состояние **на дату этого абзаца**, не текущее состояние всей функции. По завершении каждого принятого шага обновлять дату среза и статус без ретроспективного стирания ошибок.
