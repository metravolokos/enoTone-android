## Актуализация 2026-11-10

- **Закрыто для текущей коллекции:** все 3590 FLAC/MP3 файлов индексированы; страницы Albums, Artists и Album Artists существуют, виртуальный Unknown Album сохранён; реализованы обновление каталога и повторная индексация. Исторические вопросы в таблице выше остаются для аудита, но их статус на 2026-11-09 уже не отражает текущее состояние.
- **Закрыто:** Wi-Fi-only больше не является требованием; Stable Preview с постоянной подписью проверена при install-over-install, Room остаётся.
- **Открыто:** FTS, обложки, форматы без реальных образцов, восстановление очереди, release/лицензия, device performance/accessibility и финальный Android-дизайн.
- **Уточнение:** «работает последняя версия» не содержит номера APK; exact-HEAD CI и идентификацию следующей сборки проверять отдельно.

## Итоги 2026-11-11 — актуальные решения после Stable Preview #301

- **Закрыто: параметры и хранение обложек.** Действует [ADR-0067](DECISIONS/ADR-0067-permanent-album-artwork.md): постоянный `filesDir`, один мастер **до 1200 px**, без автоматического дискового LRU 64 МиБ; общий выбранный artwork на экранах настоящего альбома, independent artwork для Unknown Album; варианты ON_DEMAND/AUTO_AFTER_IMPORT, ручная очистка. Исторические `1320 px/cacheDir` неактуальны (ADR-0064 заменён).
- **Закрыто: M1-поведение.** Единый инкрементальный импорт/обновление, GENRE с остальными полями за один проход, подтверждаемая полная переиндексация, подготовленный scoped backend; контекстные меню пока остаются UX-вопросом, а не частью принятой реализации ([ADR-0066](DECISIONS/ADR-0066-indexing-finalization.md)).
- **Подтверждено базово:** PR #70/#71 объединены, CI #300/#301 зелёные, подписанная Preview #301 установлена на Huawei, ответ владельца «Работает». Не заявлять, что индивидуальные тесты offline/GET/автоматической фоновой загрузки были выполнены.
- **Согласован принцип будущих плейлистов:** альбомная мастер-обложка может быть **обложкой плейлиста по ссылке без повторного сохранения**, но функции создания/назначения обложки плейлиста ещё нет.
- **Открыто:** детальное offline-повторное использование после перезапуска, измерения GET, редкие ошибки автоиндексации изображений/очистки; FTS/сортировка/жанровые фильтры, UI контекстных меню и плейлистов, восстановление очереди после process death, полноценная проверка прочих форматов, финальная тема/лицензия/release. См. [TESTING](TESTING.md), [CURRENT_DECISIONS](CURRENT_DECISIONS.md).
