# Ревизия пользовательского интерфейса — 2026-11-10

## Объект и границы

Исходники `MainActivity.kt` и `OfflineLibraryScreen.kt` после music-first UI (`29ca45407`). Это ревизия **фактического Compose-кода**, а не визуальное тестирование установленного Huawei APK или утверждение фирменной темы. Проверена структура экранов и взаимодействий; измерения высоты/переполнения на устройстве и доступность TalkBack ещё предстоят.

## Что уже устроено правильно

- При восстановлении разрешённо сохранённых credentials открывается медиатека; новые пользователи видят подключение.
- Четыре независимые страницы, горизонтальная полоса навигации и экран настройки их видимости; хотя бы одна остаётся включённой.
- Треки и группы отображаются в `LazyColumn`, есть локальный поиск и количества.
- Мини-плеер расположен после прокручиваемого списка; большой плеер открывается отдельным прокручиваемым диалогом.
- Технические функции на домашнем экране свёрнуты, но доступны; необязательная расширенная телеметрия спрятана под явным действием.
- Стандартная тема Material 3; фирменный визуальный стиль ещё не утверждён для Android.

## Замечания и решения

| Приоритет | Наблюдение | Решение |
|---|---|---|
| P1 | Все вкладки выглядят как одинаковые `OutlinedButton`; текущая страница неотличима по компоненту | **Исправлено в данном PR**: заполненная `Button` для текущей вкладки, контурная для остальных, без собственного цвета; сохранён существующий сброс поиска и группы при переходе |
| P1 | Служебные действия доступны лишь через возврат из библиотеки, единая навигационная структура «Медиатека / Обслуживание / Настройки» ещё не оформлена | Отдельное проектное решение с UX-проверкой, без изменения в этом PR |
| P2 | Вкладки имеют горизонтальную прокрутку; на узком экране последние пункты могут быть вне видимой области | Проверить на Huawei с RU/EN; при необходимости индикатор/автопрокрутка к выбранной вкладке |
| P2 | Поиск работает внутри выбранной страницы; нет единого глобального поиска или FTS | Вернуться к M2 после UI-приёмки |
| P2 | Полный плеер реализован как `AlertDialog` с вертикальным скроллом и ограничением высоты | Проверить доступность seek/repeat/shuffle, закрытия и ориентации на реальном устройстве |
| P2 | Мини-плеер содержит текстовые Pause/Next/Player, но ещё нет полноценной доступной панели с явными состояниями кнопок и обложкой | Запланировать вместе с обложками и финальной навигацией |

## Безопасная проверка

1. Выполнить exact-HEAD CI и `python3 -m unittest tools/test_clean_library_ui_contract.py`.
2. Установить только подписанную Stable Preview **поверх** существующей; не очищать данные и не импортировать /AllMusic заново.
3. Открыть каждую из 4 страниц, проверить выделение текущей, скрытие/включение страниц и поиск.
4. Выбрать трек, проверить мини-плеер и полный плеер; проверить, что переключение страниц не останавливает воспроизведение.
5. Проверить русские/английские названия на узком экране, а затем TalkBack отдельно. Не передавать в GitHub имена личных файлов или credentials.

Изменение этого PR **не затрагивает** WebDAV, индексацию, Room, Media3, сохранённую очередь, Stable Preview signing, палитру или маскота.


## Срез UI-B — замечания по скриншотам Huawei 2026-11-10

После установки подписанной Preview с иконками нижней навигации владелец предоставил четыре скриншота: все разделы функционируют, но обычная медиатека теряет существенную высоту из-за текстовых кнопок навигации, постоянно развёрнутого поиска и двухрядного мини-плеера. При этом технические страницы не должны менять данные Room или повторно опрашивать /AllMusic.

**Данный срез:** верхняя панель 48 dp с иконками Back/Search/Pages и полной семантикой; поиск скрыт, пока не выбран (закрытие очищает запрос, предотвращая невидимый фильтр); статистика видна только для активного поиска; контекстный возврат из группы; мини-плеер 56 dp + тонкий прогресс с изображением-заглушкой, двумя строками метаданных и иконками Play/Pause, Next, Open player. Минимальные цели нажатия 48 dp. Цвета остаются Material 3.

**Не входит:** реальные обложки; детальные экраны альбомов и исполнителей; самостоятельный полноэкранный Now Playing; сортировка, глобальный FTS, редактирование очереди. Их приоритет сохраняется в [ROADMAP](ROADMAP.md).

**Huawei smoke:** установить подписанную Stable Preview поверх существующей, не чистить данные; открыть четыре раздела, раскрыть поиск, ввести и закрыть (фильтр должен очиститься), открыть альбом и выйти по стрелке, выбрать трек, проверить Pause/Resume, Next, раскрытие существующего полного плеера, прогресс, отсутствие остановки при переключении страниц. Проверить длинные имена/крупный шрифт. Оценка по скриншотам не равна полноценному тесту TalkBack.
