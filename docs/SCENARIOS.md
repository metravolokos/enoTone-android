# Каталог пользовательских сценариев

Стабильные ID для PR, аудитов и отчётов владельца. Порядок проверки — [AUDIT_PROTOCOL](AUDIT_PROTOCOL.md), команды запуска — [TESTING](TESTING.md). Требования — [REQUIREMENTS](REQUIREMENTS.md).

**Как читать:**
- «Ожидается» — **требуемое** поведение. Критерий не ослабляется оттого, что реализация пока ему не соответствует; такие места помечены ❗.
- **Проверка:**
  - **JVM** — JUnit без Android;
  - **R** — Robolectric или Compose UI на JVM;
  - **H** — вручную на Huawei на подписанной Stable Preview, установленной поверх предыдущей.
- **Автотест** — существующий класс; «нет» означает, что автоматизация отсутствует и нужна отдельная задача.
- **Последний результат** — только с номером сборки и датой. Общее «работает» засчитывается лишь тем пунктам, которые владелец назвал.

Общие условия для H: вход выполнен, медиатека владельца (около 3647 файлов) сохранена. **Полную переиндексацию и реальный выход ради проверки не запускать.** В отчётах — только коды и числа, без имён файлов, путей и учётных данных.

## События жизненного цикла

Это разные события, ожидаемое поведение определено для каждого отдельно.

| Событие | Воспроизведение | Индексация и подготовка обложек | Очередь и позиция |
|---|---|---|---|
| **Смахивание из недавних, музыка играет** | продолжает играть, уведомление остаётся (O-17) | продолжается (foreground-служба) | сохраняется сразу (`onTaskRemoved`) |
| **Смахивание на паузе** | служба может остановиться | продолжается | сохранена; при открытии — мини-плеер на паузе |
| **Пересоздание Activity** (смена темы, языка; поворот заблокирован) | не прерывается | не прерывается | экран, вкладка и прокрутка сохраняются |
| **Гибель процесса системой** | останавливается | останавливается, **сама не возобновляется**; прочитанное сохранено; «Продолжить» по кнопке | восстанавливается; во время воспроизведения позиция отстаёт **до 12 с**, на паузе — точная |
| **Принудительная остановка** (Android «Остановить») | как гибель процесса | как гибель процесса | как гибель процесса |
| **Перезагрузка** | не стартует сама | не стартует сама | восстанавливается при открытии приложения |

Погрешность позиции следует из ADR-0075: запись при паузе, перемотке, смене трека и смахивании — сразу; во время воспроизведения — каждые 12 с. Поведение индексации после принудительной остановки и перезагрузки сейчас определено реализацией (ADR-0049: без автоперезапуска), отдельного решения владельца нет — см. «Открытые вопросы».
