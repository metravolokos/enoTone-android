## Дополнение D2a (Draft PR #122, 2026-11-13)

Метрика «в обе стороны» по `git log -- settings.gradle.kts` на `89545ea`: начальный коммит `2cda186` создал 15 модулей (не PR), **0 PR добавляли модули, 1 PR удалял модули — #119** (минус 5, осталось 10). В D2a появляется **11-й `:core:ui`**, принят по ADR-0084: ресурсный контракт для Home/Now Playing, иначе потребовалось бы расширять фасады (28 ID Now Playing). В D2b новые компоненты не встраиваются в экраны до D3–D6; неиспользованные по закрытии D6 удалить. **Список D2b к удалению по завершении D6:** неиспользуемые компонентные реализации `EnoIcon`, `EnoPill`, `EnoRoundButton`, `EnoTrackRow`, `EnoAlbumTile`, `EnoLetterAvatar`, `BanditIllustration`, `EnoWordmark`, `EnoPlayingIndicator` — по реальным ссылкам из экранов; компоненты до D3–D6 намеренно не используются. Устаревшие `ic_action_*`/`ic_nav_*`/`ic_music_*`, старый Graphite-код и ресурсные фасады `NowPlayingIds`/`HomeScreenIds` удалять **только после замены вызовов на шагах D3–D5**, не в D2.
