# ADR-0005: Системное воспроизведение Media3

Дата: 2026-11-08 | Статус: предложено | Автор: ChatGPT

## Контекст и варианты
Media3 ExoPlayer+MediaSessionService упрощает аудиофокус, Bluetooth и фон; свой audio engine повышает риск. Выбрано для M3, **не реализовано в M0**. Проверять после M3 на Huawei и USB DAC.

## Решение и последствия
Считать выбранные решения границей соответствующего этапа; не изображать запланированное работающим в M0. Новые зависимости и отклонения фиксировать новым ADR.

## Проверка / пересмотр
Проверка исходников, CI, mock и реального Huawei в соответствующем этапе; при расхождении — новый ADR с измерениями.
