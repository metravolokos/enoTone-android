# ADR-0035 — M4-C: repeat и shuffle непосредственно в Media3

Дата: 2026-11-08. Статус: Draft до CI и Huawei.

## Контекст

На Huawei Preview #91 владелец подтвердил: музыка воспроизводится и переключается, кнопки enoTone есть в собственном уведомлении. Отдельная системная мультимедиа-панель Huawei, по наблюдению владельца, не поддерживает сторонние плееры — это особенность оболочки, а не дефект enoTone. PR #25 объединён с зелёным CI #91. M4-B уже использует нативный плейлист Media3, поэтому режимы повтора и перемешивания должны использовать штатные Player-поля, не вторую самописную очередь.

## Решение

- Добавить в интерфейс две отдельные кнопки при выбранном треке. **Повтор** циклически переключает `REPEAT_MODE_OFF` → `REPEAT_MODE_ONE` → `REPEAT_MODE_ALL` → `OFF`. **Случайный порядок** включает/выключает `shuffleModeEnabled`.
- Все переключения выполняются исключительно над `ExoPlayer` в существующей приватной `MediaSessionService`. Media3 отвечает за порядок, автопереход, состояния кнопок в System UI и гарнитуре. Не хранить дублирующий собственный индекс и не делать `setMediaSources` при смене режима.
- При переподключении Compose-экрана прочитать текущие repeat/shuffle из службы; отслеживать `Player.Listener.onRepeatModeChanged` и `onShuffleModeEnabledChanged` для актуального UI. Режимы продолжают действовать в фоне, пока работает процесс.
- Значения по умолчанию: повтор выключен, случайный порядок выключен. Режимы не сохраняются после уничтожения процесса; не добавляем Room migration, Intent extras, запросы WebDAV, логи или сетевые обходы.
- Доступ к Cloud.Mail.ru, HTTPS-only, no-redirect, HTTP 206/Content-Range, per-track size/ETag, GMS-free gate и собственное медиауведомление не меняются.

## Проверка

- JVM `PlaybackModesTest`: точный цикл из трёх режимов, безопасный reset для неизвестного значения. Python contract проверяет отсутствие собственного shuffle-планировщика и наличие Player callback состояния.
- CI на точном HEAD: Android/JUnit/lint, Room v1/v2, GMS-free byte scan, Preview signing и артефакт APK.
- Huawei новой отдельной Preview: один раз сохранить список /AllMusic; в медиатеке выбрать короткий трек, проверить повтор одного; выключить повтор и проверить переход, включить повтор всей очереди для маленького результата поиска; проверить shuffle с несколькими треками и что он не выбрасывает из выбранной очереди. Свернуть приложение и убедиться, что управление и звук продолжаются.
- Не публиковать приватные названия, пароли, теги, URL и скриншоты с личными уведомлениями.

## Ограничения

Настройки shuffle и repeat пока не возвращаются после уничтожения процесса. Не предполагаем, что отдельная системная мультимедиа-панель Huawei обязана отображать кнопки стороннего приложения; достаточно собственного уведомления, если контроль работает. Не заявляем тест пройденным до проверки на Huawei.
