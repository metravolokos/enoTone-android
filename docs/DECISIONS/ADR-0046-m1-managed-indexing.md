# ADR-0046 — M1 управляемая индексация: ограниченные порции, Wi-Fi и пауза

Дата 2026-11-09; статус Draft до CI exact-HEAD и Huawei smoke.

## Контекст
В Stable Preview #179 отработало 52/52 MP3/FLAC тегов за 60 GET / 3932160 байт без ошибок. Уже сохранено 62 из 3590. Порядка 68 ручных однопорционных запусков — неудачный UX. В #181 владелец подтвердил Album Artist как приоритетного исполнителя.

## Решение (первый безопасный этап)
- **Никакой автоматической фоновой индексации** при входе, запуске приложения, воспроизведении, загрузке списка или новом APK. Отдельная явная кнопка «Начать ограниченную сессию», отмена, пауза, возобновление из Room. Никакой новой загрузки списка через PROPFIND.
- Одна сессия — **не более четырёх** последовательных уже существующих бюджетных проходов `PilotTagIndexer.run(100)`. Каждый проход ограничен **60 GET, 4 МиБ**, мягким тайм-бюджетом примерно 180 сек между файлами. Сумма одной сессии не более **240 GET и 16 МиБ**, проверяемая на выходе каждого прохода. Между порциями пауза 1,5 сек. Это первое аппаратное испытание; никакого бесконечного while.
- **Wi-Fi-only по умолчанию**: проверка текущей сети `ConnectivityManager` перед каждой порцией и **каждым следующим файлом**. Пользователь может отдельно разрешить мобильную/VPN сеть на следующую сессию, осознавая расход трафика. Смена сети внутри одного файла может завершить его оставшиеся ограниченные Range GET; на следующем file boundary остановка. Разрешение `ACCESS_NETWORK_STATE` только для локального чтения типа сети.
- Перехват Android `MainActivity.onStop()` **отменяет только индексирующую корутину** и устанавливает состояние PAUSED. Закрытие/блокировка экрана не запускает фонового сервиса. Media3 playback продолжает работать независимо.
- При любом повторяемом сетевом сбое 429/5xx/timeout или неверной авторизации прерываем дальнейшие порции; нет автоматического backoff/retry-loop. Обновление конкретного checkpoint происходит только после подтверждённого завершения соответствующего файла по прежнему CAS/ETag правилу, а уже сохранённые файлы пропускаются. Завершившийся ранее файл не скачивается повторно.
- Текущие кнопки 10/20/100 и стабильная схема Room/Android Keystore/Media3/парсер тегов (Album Artist включая TPE2/ALBUMARTIST) не меняются. Только стандартный Material Design.

## Пределы и последующие решения
Первым на Huawei — установка подписанного APK поверх #181, проверка сохранности 62 записей и входа, одна сессия **на Wi-Fi** с остановкой/последующим ручным Resume и числовым отчётом GET/bytes/errors. После приёмки можно обсуждать более длинную foreground-сессию, сетевую адаптацию, WorkManager либо foreground service и протокол возобновления при выключенном экране. Ни одна из этих функций не включена в текущий PR.
