# ADR-0063 — миниатюры в списках треков (M2-ART-B)

Дата: 2026-11-10. Статус: Draft; до Huawei-приёмки не считать проверенным.

## Контекст

После PR #66 единый импорт/жанры и Room v4 уже находятся в `main`.
Существующие обложки альбомов и активного трека загружаются по запросу через
`ArtworkPreviewRepository`, ограниченный HTTP Range и приватный WebP LRU.
В списках треков изображений пока не было.

## Решение

- Каждая **составленная** строка `items(visible, key = { it.id })` получает декоративную
  квадратную миниатюру 44 dp и текст заголовка/исполнителя с выравниванием
  относительно изображения. Строки вне окна LazyColumn не инициируют запрос.
- Имеющийся `preparedById` даёт ID, кодированный путь, размер и ETag.
  Дополнительного Room-запроса при прокрутке нет; Media3, очередь, поиск,
  заголовок альбома и действия воспроизведения не меняются.
- Одна переиспользуемая `ArtworkPreviewRepository` на экран продолжает
  ограничивать число одновременных запросов двумя, использует 32-МиБ кэш
  512 px и существующие строгие сетевые лимиты. Без пароля — placeholder.
- Во время состояния `LOADING` или `BUFFERING` новые запросы обложек
  приостанавливаются; после перехода в READY отображаемые строки смогут
  загрузиться. Аудио всегда приоритетнее изображения.
- Отсутствующая или повреждённая обложка показывает нейтральный значок,
  а не вымышленную картинку. Содержимое обложки не дублирует доступное
  название трека в TalkBack.

## Ограничения и следующие шаги

Это **не** массовая загрузка обложек при импорте и не переиндексация 3590 файлов.
При длительной ручной прокрутке новые видимые строки могут последовательно
инициировать сетевое чтение. В следующих срезах остаются крупное изображение
1320 px для Now Playing, выборочная инвалидация кэша после явного реиндекса,
расширение интерфейса исполнителей и оптимизация повторяющихся обложек
у треков одного альбома.

## Приёмка

1. CI exact HEAD: Android/JUnit/Lint, Python contract, Room v1–v4, GMS-free.
2. Сборка Stable Preview только из `main`, после успешного CI.
3. Huawei: обновление поверх установленной Stable Preview без удаления
   3590 записей и сохранённых логина/пароля; список треков, миниатюры,
   поиск, запуск трека и переключение вкладок.
4. При быстрых прокрутках и включённом воспроизведении не должно быть
   заметных задержек звука; при ошибках изображения музыка продолжает играть.
5. Никаких личных путей, ETag, URL, логинов и тегов в Git/CI.
