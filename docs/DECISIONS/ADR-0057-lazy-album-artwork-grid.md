# ADR-0057 — сетка альбомов с ленивыми обложками (M2)

Дата: 2026-11-10. Статус: Draft PR, аппаратная проверка ещё впереди.

## Основание

Владелец на Huawei подтвердил, что Stable Preview #251 отображает встроенную обложку MP3/FLAC в мини-плеере и полном диалоге, не задерживает воспроизведение. Текущий дизайн оставляем и продолжаем функциональность. Библиотека /AllMusic плоская, индексирует 3590 треков, альбомы сгруппированы локально по сохранённым тегам (около 832 групп).

## Решение

- Корневой раздел **Альбомы** показывает адаптивную сетку карточек с обложкой, названием и исполнителем альбома (или существующим fallback), количеством треков. Нажатие сохраняет прежний переход к списку треков альбома. Остальные разделы сохраняют текущий вид.
- Использовать `LazyVerticalGrid(GridCells.Adaptive(minSize = 148.dp))` — изображения запрашивают **только композиционно видимые карточки**, не все 832 группы. При уходе карточки из viewport Compose отменяет её `LaunchedEffect`; при возвращении готовая обложка берётся из дискового кэша.
- Каждому реальному альбому сопоставлять **один** стабильный представитель из уже подготовленного RAM snapshot (`preparedById`). Это не делает новых запросов Room и не вызывает массовой переиндексации. Для агрегата **Неизвестный альбом** (разные треки без ALBUM) не выбирать произвольную обложку — всегда заглушка.
- Общий `ArtworkPreviewRepository` ограничивает **двумя** одновременно выполняющимися запросами для карточек и текущего плеера; каждый использует уже проверенный HTTPS WebDAV Range и лимиты на входные данные. Существующий приватный кэш WebP с общим бюджетом 32 МиБ используется повторно, не дублируется. Без Google Play Services и дополнительных разрешений.
- При ошибке сети или отсутствии встроенного изображения карточка остаётся кликабельной с нейтральной заглушкой.

## Не меняется

Room v2, структура /AllMusic, пароли в Keystore, Media3/очередь/буферизация/фоновое воспроизведение, полноразмерный плеер, домашняя страница и пять навигационных кнопок, палитра и утверждённая подпись Stable Preview.

## Дальнейшие этапы

- Детальная страница альбома с единым header, порядком треков/номером диска, годом и запуском всех треков.
- Страницы исполнителей и исполнителей альбомов; отдельно решить изображения артистов (их нельзя автоматически считать обложками).
- Поиск/сортировка и полноценный Now Playing.

## Проверка

Exact-HEAD CI: сборка/JUnit/Lint и новый UI-контракт с LazyVerticalGrid, двумя сетевыми слотами, Unknown Album без ложной обложки. На Huawei после установки поверх прежней Preview проверить: раздел Альбомы, плавность прокрутки, появление изображений по мере видимости, открытие/возврат из альбома, не изменившуюся работу треков, повторный показ картинки из кэша, отсутствие массового GET или повторного индексирования.
