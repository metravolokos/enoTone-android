# ADR-0036 — M5-A: временный полный кэш текущего трека

Дата: 2026-11-08. Статус: Draft до CI и теста Huawei.

## Контекст
Preview #94 успешно проверена на Huawei, PR #26 принят. M5 требует скачивать текущий трек полностью даже при паузе, затем загружать следующий, использовать локальный seek и удалять временные данные при завершении.

## Выбранное решение
- Использовать официальные Media3 SimpleCache, CacheDataSource и CacheWriter вместо отдельного самописного downloader. Upstream — действующий проверенный HTTPS GMS-free WebDAV DataSource: no redirects, HTTP 206/Content-Range, per-track ETag/size.
- Начать фоновой worker на **текущем** треке при Media3 onMediaItemTransition. Он работает независимо от play/pause. При переключении отменить старый worker. Предзагрузка следующего — только отдельный M5-B.
- Основной playback DataSource читает уже закэшированные сегменты, а отсутствующие — по сети; режим read-only не захватывает cache-hole lock фоновой загрузки и не задерживает первый звук. После полной загрузки новые открытия/seek могут читать локально. Гарантированное переключение уже открытого сетевого соединения посреди трека — отдельное улучшение, не заявлять его здесь.
- App-private cacheDir. Содержимое предыдущей сессии стирать при создании кэша, текущие файлы — после освобождения плеера и worker. Обычная Room и база списка /AllMusic не изменяются.
- Полный фоновый GET только для файлов до 256 МиБ, LRU максимум 512 МиБ, резерв свободного места не менее 128 МиБ. При недоступности места/ошибках продолжать обычный потоковый playback.
- Только SHA-256 от локального ID, размера, ETag в индексе кэша. Не передавать путь, filename, account, пароль или ошибки в публичные логи, телеметрию и GitHub.
- Счётчик прогресса в KiB обновлять локально раз в секунду на открытом экране.

## Ограничения
- Нет prefetch следующего, Wi-Fi only policy, гарантированного бесшовного переключения уже открытого HTTP-потока или доказанного сокращения трафика. Первый background GET параллельно playback может увеличить трафик: измерить на Huawei, не скрывать.
- Не запускать обработку или загрузку всех 3590 файлов. При файлах за пределом бюджета streaming остаётся доступным.

## Проверки
- JVM: TransientCachePolicyTest на размер, резерв места, непрозрачный versioned cache key.
- Android CI на точном HEAD: build/JUnit/lint, Room schemas, строгий GMS-free APK byte scan, Preview identity/signing и артефакт.
- Huawei новой Preview: один раз импортировать только список /AllMusic, включить короткий MP3, после 1–2 секунд нажать паузу и проверить, что число кэшированных KiB продолжает расти до COMPLETE. Продолжить/свернуть, удостовериться в прежнем воспроизведении. Ошибки/числа присылать без названий файлов или пароля. Seek без соответствующей кнопки UI отдельно не считается проверенным.
