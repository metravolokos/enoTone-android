# ADR-0016: Room v1 для плоской медиатеки и безопасный снимок списка

Дата: 2026-11-08 | Статус: эксперимент до зелёного CI | Автор: ChatGPT

## Контекст
На Huawei подтверждено: `/AllMusic` — **3590 аудиофайлов, 0 пропущенных и 0 некорректных записей**, полученных одним WebDAV `Depth:1` через M1 PR #4. Важнее сохранить список надёжно, чем повторять PROPFIND при каждом открытии.

## Решение
- **Room 2.8.5 + KSP 2.3.10**: первичная модель `RemoteTrackEntity`, DAO и БД v1. Версии фиксированы в Gradle catalog.
- Стабильный ID — SHA-256 от идентификатора источника и URL-кодированного пути, **без ETag**. Источник из нормализованного e-mail хэшируется; пароль не попадает в БД.
- Элементы не объединяются между аккаунтами. Признаки версии — ETag, размер, lastModified. При неизменной версии будущие теги сохраняются, при изменении обнуляются для повторного извлечения.
- Вставка/обновление атомарно через `RoomDatabase.withTransaction`. Один неполный ответ не удаляет записи: в данном срезе SQL DELETE **не выполняется вообще**; для отсутствующих на полной выдаче файлов увеличивается счётчик отсутствия.
- Схема Room экспортируется при сборке в `core/database/schemas`; JSON v1 нужно включить в Git и проверить перед release. Миграции без destructive fallback.
- Список имён/путей/ETag остаётся в приватной БД Android; в логах/PR только счётчики, и backup/transfer для файлов/БД выключены.

## Альтернативы
- Хранить всё в Preferences/JSON — не подходит для инкрементальности/FTS и 3590+ файлов.
- Сбрасывать всю таблицу при сканировании — опасно: теряются теги, риск удаления при сетевых ошибках.
- Полный индексатор с извлечением всех тегов сразу — отклонён для этого небольшого среза.

## Границы готовности
На этом этапе Room компилируется и логика сравнения покрыта unit-тестами. **Кнопка M1 ещё не пишет в БД**; нет миграций на устройстве, FTS, тегов и фоновых задач. Их добавлять отдельным PR после CI. Проверить generated SQL Room/KSP, versioned schema и эмуляторные/instrumentation тесты до релиза. Сервис не хранит credentials.

## Проверка
CI `core:database` и `data:library` compile/tests, общий Android lint/GMS scan и строгий APK. При наличии успешного CI ещё не означает готовность сохраняемой медиатеки на Huawei.
