## Контекст и варианты
Сравнить системный MediaMetadataRetriever через Range с jaudiotagger/собственным парсером. На M0 не реализуется. В M1 тестировать mp3/flac/ogg/opus/m4a/wav и без полной загрузки.

## Решение и последствия
Считать выбранные решения границей соответствующего этапа; не изображать запланированное работающим в M0. Новые зависимости и отклонения фиксировать новым ADR.

## Проверка / пересмотр
