# ADR-0055 — домашний экран, пятиэлементная навигация и отдельные настройки

Дата: 2026-11-10. Статус: реализация в PR; требуется CI exact HEAD и приёмка на Huawei.

## Решение владельца

Работающую техническую Stable Preview использовать как основу. Добавить отдельный домашний экран и нижнюю панель из пяти иконок в строгом порядке:

**Домой → Треки → Альбомы → Исполнители → Исполнители альбомов.**

Иконки сохраняют компактную высоту 52 dp и минимум текста; изменения художественного стиля, иконографии и фирменной палитры пока не приоритет. Иконка «Домой» постоянна; четыре медиа-раздела можно независимо скрывать в настройках, оставляя как минимум один доступный.

Старый первоначальный экран (подключение Cloud.Mail.ru, хранение credentials в Keystore, ручное обновление каталога, индексирование и технические операции) становится **экраном настроек**, доступным по иконке вверху домашнего экрана. Управление видимостью категорий переезжает из диалога медиатеки на экран настроек. Технические операции остаются свёрнутыми по умолчанию. После восстановления credentials стартовая точка — Home, а не автоматический переход к списку треков.

## Архитектурный срез

- `EnoToneHomeScreen` — отдельный экран с настройками и входом в медиатеку.
- `CompactLibraryNavigation` — общий нижний бар Home+4. В обычном режиме без надписей, локализованные `contentDescription`, 48 dp hit targets, выбранный пункт различим фоном.
- `LibraryVisibilitySettings` — существующий `LibraryPagePreferences` и `LibraryPageVisibility.withVisibility`, без смены ключей SharedPreferences. Скрытие категорий не влияет на хранимую медиатеку или индексацию.
- `MainActivity` управляет Home / Library / Settings. `OfflineLibraryScreen` принимает начальную вкладку, выбранную на Home. `onBack` ведёт на Home, возврат из выбранной группы остаётся внутри библиотеки.
- Главная страница не обращается к WebDAV и не запрашивает Room. Действующие механизмы индексации, данных и воспроизведения остаются нетронутыми. При возврате из библиотеки уже работающий MediaSessionService не останавливается.

## Ограничения и последующие этапы

Это навигационный срез, а не готовое содержимое Home. Виджеты недавних альбомов, обложки, постоянный мини-плеер на Home, полноценный экран Now Playing, портреты исполнителей, визуальный дизайн иконок — отдельные задачи. Дополнительные данные из облака без явного действия пользователя не запрашиваются.

## Проверки

1. CI exact HEAD: Kotlin compile, JUnit, UI contract, lint, Room schema, no-GMS, стабильная Preview подпись.
2. Установка только Stable Preview поверх предыдущей, без удаления данных. При восстановленных credentials приложение показывает Home; настройки доступны по шестерёнке.
3. Пять иконок в нижнем баре, выбор любой категории открывает её данные без сети; Home возвращает на Home. Скрыть одну категорию из Settings, вернуться, проверить четыре оставшиеся иконки и сохранение настройки после перезапуска.
4. Открыть настройки: connection/Keystore, обновление /AllMusic, ручной индекс и технические диагностики присутствуют. Не запускать повторную индексацию ради проверки UI.
5. Воспроизведение выбранного трека не прекращается при переходе Home↔Library; проверить также узкий экран и TalkBack-описания.
