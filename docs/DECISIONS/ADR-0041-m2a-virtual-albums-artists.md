# ADR-0041 — M2-A: локальные виртуальные альбомы и исполнители

Дата: 2026-11-09. Статус: Draft до CI/Huawei.

## Контекст
Плоская папка /AllMusic содержит 3590 файлов; Room хранит список и только часть разобранных тегов (последний подтверждённый пилот — 30 файлов). В соответствии с USER_SPEC_RU.md виртуальные группы должны строиться из **сохранённых тегов**, а не из отсутствующей структуры каталогов. Аудиодвижок M6-B принят на Huawei Preview #157, не изменять.

## Альтернативы и решение
1. Сразу читать теги всех 3590 объектов: отвергнуто — массовые GET, непроверенный бюджет трафика, слабая воспроизводимость.
2. Считать все файлы без тегов одним «Неизвестным альбомом»: отвергнуто — ложная структура и гигантская группа, неудобная навигация.
3. Строить виртуальные альбомы/исполнителей **в RAM из одного уже существующего Room snapshot**, показывая только известные теги: выбрано. Все необработанные файлы остаются в «Треках».

## Реализация
- `OfflineLibraryGrouping` — чистый Kotlin, без Room/Android/network; альбомы по нормализованным NFC + lowercase (album, albumArtist или artist), чтобы разные исполнители с одинаковым названием альбома не сливались; для сборников предпочтение `albumArtist`. Исполнители — по artist, с резервом albumArtist.
- Три вкладки со стандартными цветами Material Design, локальная фильтрация и детальный список треков группы. При выборе песни существующий `playQueue` получает только видимый локальный контекст группы: **плеер, WebDAV DataSource, CacheWriter, MediaSession и Room DAO не меняются**.
- Группы не включают файлы без соответствующих тегов; экран честно предупреждает о неполном покрытии. Нет новых PROPFIND/GET, background jobs, GMS или ключей.

## Проверка
JVM: 3590 untagged → ноль ложных групп; компиляции с albumArtist и разными артистами; Unicode NFC, регистр, поиск, стабильная принадлежность id. CI: mock WebDAV, Android build/JUnit/lint, Room schema, GMS/APK. Huawei: существующие 3590 файлов в «Треках» без повторного импорта в **этом пакете Preview**; группы только из тегированных; открыть группу, запустить песню, проверить Next и возврат; не раскрывать имена файлов на GitHub.

Вне этапа: FTS, обложки, расширение парсера, массовая индексация, сортировка по номеру дорожки и окончательное оформление UI.

## Уточнение после Huawei Stable Preview #172
Пользователь принял update-in-place #169 и opt-in Keystore/Forget #172: базовая Room и авторизация теперь сохраняются между обновлениями Stable Preview. Исторические 30 обработанных тегов других изолированных пакетов НЕ перенесены; на текущем Stable Preview заполненность Album/Artist неизвестна. M2-A переоснован на актуальном `main` без изменения хранилища, парсера или Media3. Новые группы могут быть пусты до ограниченного разрешённого пилота, но список Tracks остаётся полным. Проверять на `app.enotone.android.preview` с уже сохранённой базой, не выполняя повторный импорт.
