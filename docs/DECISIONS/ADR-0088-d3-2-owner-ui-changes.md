# ADR-0088 — D3.2: закреплённый заголовок вкладок и настройка «Прозрачные панели»

**Дата:** 2026-11-14. **Статус:** принято владельцем; реализация — PR D3.2. **Основание:** проверка владельцем сборки после #129 на Huawei Nova 15 Pro и его решения 2026-11-14 (`DECISIONS_android_v2_ui`, строки «D3.2»; задание `TASK_D3-2_owner_changes`). Частично заменяет ADR-0086 (прокрутка вариант B на вкладках, ручка «Свернуть»).

## Контекст
После D3.1 владелец посмотрел сборку и решил: (1) на «Сейчас играет» не нужна ручка — экран закрывается только жестом; (2) на вкладках-категориях заголовок не должен сворачиваться — список идёт под ним; (3) подписи поиска должны называть категорию; (4) размытие под мини-плеером и нижней панелью хочется попробовать, но «у нас не Apple Music» — только как настройку; (5) обложке «Сейчас играет» нужны тонкая обводка и более заметная тень. Пункт (4) — новая пользовательская настройка, по AUDIT_PROTOCOL §4 требует ADR.

## Решение 1 — заголовок вкладок «Песни», «Альбомы», «Артисты», «Авторы»
1. **Закреплённый заголовок поверх списка (выбрано).** Название, значок поиска, счётчик (на «Песнях» — «Играть»/«Перемешать») лежат над списком; отступ списка сверху = измеренная высота заголовка. Когда список прокручен, у заголовка фон 84 % + размытие содержимого под ним (Haze, та же обёртка `EnoBlurState`) и линия `line` 70 %. Плюсы: поиск и действия всегда на виду, решение владельца; без новой зависимости. Минусы: на «Песнях» заголовок занимает ≈ 190 dp постоянно.
2. **Заголовок в колонке над списком без наложения.** Проще, но без «стекла» и с резкой границей; список не уходит «под» заголовок, как просил владелец.

Полоска варианта B (ADR-0086) остаётся только на экранах альбома и исполнителя: там шапка — крупная обложка, закреплять её нельзя.

## Решение 2 — «Прозрачные панели»
1. **Настройка в «Оформлении», по умолчанию выключена (выбрано владельцем).** Отдельный файл настроек `enotone_ui_effects_v1` / `translucent_dock` — данные `UiAppearance` (`enotone_ui_appearance_v1`) не трогаются. Включено: мини-плеер и нижняя панель — свой цвет на 72 % + размытие содержимого вкладки 24 dp; выключено — непрозрачные, как в макетах. В `:core:ui` — `LocalEnoDockBlur`, компоненты настроек не читают.
2. **Флаг в коде без настройки.** Минимально, но владелец сможет посмотреть только в отдельной сборке; решение владельца — настройка.
3. **Всегда включено.** Отклонено владельцем.

### Дополнение 2026-11-14 (D3.3)
Владелец проверил D3.2 на Huawei: переключатель оставить («с ним гораздо лучше») и распространить на верхние панели. «Прозрачные панели» управляют теперь и закреплённым заголовком вкладок, и полоской прокрутки альбома/исполнителя: выключено — сплошной фон + линия, включено — 84 % + размытие 18 dp. Один `LocalEnoDockBlur` на весь каркас, верхние панели — `Modifier.enoTopBarBackground`.

## Остальное (без вариантов — прямые решения владельца)
- «Сейчас играет»: ручки и кнопки «Свернуть» нет, закрытие — свайп вниз и системное «Назад».
- Поиск: «Найдено N песен / альбомов / артистов / авторов» (`plurals`), «Ничего не нашлось».
- Обложка «Сейчас играет»: обводка 1 dp `coverRim` (белая 35 % / чёрная 35 %), тень 28 / 64 dp цвета `shadowStrong` — палитра v1.5 (`enotone-design` `a2afd4c`). Тень рисуется `Modifier.enoShadow` (shadow layer как CSS `box-shadow`), а не тенью высоты, которая на тёмном фоне почти не видна.

## Последствия
- ADR-0086: «ручка Свернуть» и вариант B на вкладках-категориях заменены; модель навигации и Haze без изменений.
- Новые строки RU/EN; `library_count` и `library_group_count` удалены.
- Новая настройка — кандидат в ревью «что удалить» после месяца использования: если владелец её не включает — убрать вместе с `LocalEnoDockBlur`.
