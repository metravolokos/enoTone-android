# ADR-0086 — каркас навигации Android v2 (D3)

**Дата:** 2026-11-14. **Статус:** принято; реализация — PR D3. **Основание:** DESIGN_PLAN (D3), ADR-0084 (`:core:ui`), ADR-0052 (видимость страниц), ADR-0080 (выход), решения владельца по Android v2 (`DECISIONS_android_v2_ui`, 2026-11-12), решение владельца 2026-11-14: D3 делает Claude, размытие — библиотекой Haze.

## Контекст
До D3 навигация была набором флагов `showingLibrary` / `showingSettings` / `showingDiagnostics` в `DiagnosticScreen` и `BackHandler` с `when`; нижняя панель — M3 `NavigationBar` со значками ADR-0073, мини-плеер рисовал каждый экран сам. Макеты Android v2 требуют плавающую панель «Домой · Песни · Альбомы · Артисты · Авторы», закреплённый мини-плеер, «Сейчас играет», сворачиваемое свайпом, «Домой» C2 и прокрутку «вариант B» — полоску с размытием содержимого под ней.

## Решение 1 — модель навигации
1. **Своя модель `AppNavState` + чистые переходы `AppNavigator` (выбрано).** Плюсы: без зависимостей; пять плоских вкладок и неглубокий стек («Настройки» → «Диагностика») проверяются JVM-тестами; сохранение — строкой через `rememberSaveable`. Минусы: стеки внутри вкладок (альбом → исполнитель → альбом) придётся добавить в D4 самим.
2. **`androidx.navigation:navigation-compose`.** Плюсы: стандартные стеки, deep links. Минусы: новая runtime-зависимость (порог AUDIT_PROTOCOL §4), маршруты строками, тесты требуют Android; для текущей глубины избыточно.

«Сейчас играет» — не элемент стека, а слой поверх любого экрана (как с #117: открытие из уведомления). «Назад»: свернуть «Сейчас играет» → закрыть альбом/исполнителя внутри медиатеки → «Диагностика» → «Настройки» → вкладка → «Домой» → выход. Повтор активной вкладки — прокрутка в начало (или закрытие открытого альбома). Скрытая страница (ADR-0052) пропадает из панели, открытая — уводит на «Домой». Выход из аккаунта — на «Домой».

## Решение 2 — размытие под полоской прокрутки
1. **Haze `dev.chrisbanes.haze:haze` 1.7.2 (выбрано владельцем 2026-11-14).** Apache-2.0, чистый Compose, без GMS и сети; размывает содержимое *под* элементом (RenderEffect на API 31+, RenderScript на более старых). Версия 1.7.2 — последняя ветки 1.x, собрана под Compose 1.10 и не поднимает Compose приложения (BOM 2026.06 = 1.11.3); Haze 2.x тянет Compose 1.12 — переход отдельным решением. Haze — `implementation` только в `:core:ui`, наружу видна обёртка `EnoBlurState` / `Modifier.enoBlurSource`: замена библиотеки не затронет экраны.
2. **Без размытия, фон ≈ 94 % непрозрачности.** Плюсы: ноль зависимостей. Минусы: расходится с утверждённым макетом.

## Что входит в D3
- `:core:ui`: `EnoBottomBar`, `EnoMiniPlayer` (две кнопки, прогресс; слой буфера — параметр, данных пока нет, D5), `EnoCollapsingStrip` (название + пилюли «Играть»/«Перемешать» по макету `10_songs_scrolled`), `EnoShuffleAllCard` (Бандит в наушниках); галерея `ShellGallery` и эталоны Roborazzi.
- `:app`: `AppNavigator`, `AppMusicShell` (вкладки + закреплённые мини-плеер и панель), `AppNowPlaying`; медиатека без кнопки «назад», заголовок/поиск/кнопки прокручиваются вместе со списком; общий `LibraryViewModel` для «Домой» и вкладок.
- «Домой» C2: заголовок, вход в «Настройки», «Перемешать всё · N песен».
- «Сейчас играет»: ручка «Свернуть» вместо стрелки, свайп вниз.

## Что не входит (D4–D6)
Секции «Недавно добавленные» (нужна дата добавления — M6-0/6, `firstSeenEpochMs`), вёрстка списков, альбома, исполнителя, «Сейчас играет», пустые состояния с Бандитом, «Настройки». Кнопки поиска на полоске нет: в UI Icons v1 нет значка поиска — запросить в `enotone-design`.

## Последствия
- Удалены `CompactLibraryNavigation`, `SettingsNavigation`, значки `ic_nav_home/artists/album_artists`; мини-плеер ADR-0073 заменён.
- `LibraryViewModel` создаётся при входе в аккаунт уже на «Домой» (чтение Room для числа песен и «Перемешать всё»); сеть при этом не используется.
- `LibraryViewModel.onOpenRequest` больше не вызывается каркасом (страницу выбирает вкладка) — кандидат на удаление в ревью «что удалить» D3.

## Проверка
JVM `AppNavigatorTest`; Compose UI: «Домой», мини-плеер, «Сейчас играет» (ручка), маршрут «Настройки»; Roborazzi `shell_*` в обеих темах; Huawei — сценарии NAV/PLAY/REST, обе темы, свайп вниз, повтор вкладки.
