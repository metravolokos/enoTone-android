# ADR-0056 — первый пользовательский показ встроенной обложки, только для активного трека

Дата: 2026-11-10. Статус: предложено, ожидается CI и аппаратная приёмка.

## Основание

Владелец подтвердил установку и работу Stable Preview #243 на Huawei. Текущий внешний вид оставляем, далее выполняем исходное ТЗ по функциональности. До этого PR существовал лишь `EmbeddedArtworkLocator`: обнаружение MP3 APIC/FLAC PICTURE без извлечения данных и без UI. В медиатеке уже хранится индекс всех 3590 файлов. Повторная индексация ради картинок запрещена.

## Первый ограниченный шаг

- Извлекать **одно** встроенное изображение только после выбора/восстановления **текущего Media3 trackId**. При пролистывании треков, альбомов, исполнителей, настройках и запуске приложения без воспроизведения новых Range запросов быть не должно.
- `EmbeddedArtworkPayloadReader` получает диапазон из утверждённого `EmbeddedArtworkLocator`. Читает только payload до **4 МиБ**, отклоняет неполные ответы, не скачивает аудиофайл целиком. Сеть: существующий `WebDavRangeReader` (HTTPS, точный 206 Content-Range, проверка ETag при наличии, максимум 128 GET и 8 МиБ в рамках одного обращения, таймаут).
- На Android — проверка размера изображения **до декодирования**, допустимые JPEG/PNG/WebP, до 8192 px и 40 млн исходных пикселей; downsample и 512 px preview. Невалидный файл даёт музыкальную заглушку; воспроизведение от этого не зависит.
- `cacheDir/enotone-artwork-v1`: только закрытые миниатюры WebP, ключ SHA-256 от аккаунта, стабильного ID, пути, размера и ETag; предельная сумма **32 МиБ**, LRU по lastModified, автоматическое удаление лишнего. Обложки не пишутся в Room, исходные файлы или резервную копию. Нет внешнего API и сервисов Google.
- Отображение текущей обложки в компактном мини-плеере и существующем диалоге полного плеера. Дизайн, оформление кнопок и нижняя навигация не пересматриваются. Полный Now Playing — отдельный этап.

## Не входит

- Массовый сбор изображений 3590 файлов, сетевые запросы при открытии сетки альбомов;
- 192/1320 px варианты, полноценная сетка альбомов, страница исполнителя, подбор портретов исполнителей;
- offline-сохранение аудио и автоматическое обновление медиатеки.

Следующие PR: превью альбомов с бюджетом видимых элементов и дедупликацией повторно используемых обложек; детальные экраны альбомов/исполнителей; 1320 px обложка для полноценного Now Playing. Не выдавать текущую 512 px превью за оригинал.

## Приёмка

Exact-HEAD CI: JUnit с синтетическими MP3/FLAC, неразрушающее чтение, границы и отмена, contract tests, Lint, Room schema, no GMS. Затем подписанная Stable Preview **поверх предыдущей установки**. На Huawei выбрать трек FLAC/MP3 со встроенным изображением и убедиться, что оно появилось в мини-плеере и диалоге; переходы Next и выбор трека без обложки; перезапуск — кэш, отсутствие повторного обязательного индексирования; ошибки картинки не останавливают музыку. Поскольку реальная подборка пользователя неизвестна, не заявлять аппаратную поддержку изображений проверенной до его отчёта.
