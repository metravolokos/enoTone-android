# ADR-0043 — M0-K: добровольное сохранение WebDAV входа через Android Keystore

Дата: 2026-11-09. Статус: Draft (нужны exact-HEAD CI и Huawei smoke).

## Контекст
Huawei принял установку Stable Preview #169 поверх #167 с сохранением Room. Однако пароль внешнего приложения Cloud.Mail.ru требуется после каждого запуска: в M0 он умышленно был только в RAM. Пользователь запросил устранить повторный ввод без потери приватности и без изменений работающего Media3/WebDAV.

## Выбор и ограничения
- Только **явная** кнопка «Сохранить вход на устройстве». Ввод/редактирование полей НЕ пишет данные на диск. Кнопка удаления стирает сохранённую запись и ключ, очищает поля; уже играющий Media3 session не останавливает.
- AndroidKeyStore AES-256/GCM/NoPadding, случайный IV (12 байт), tag 128 бит, AAD с версией протокола. Ключ непереносим, не экспортируется и не включается в APK/GitHub; один alias на одно Android-приложение. Новый текст шифруется при каждом сохранении с новым IV.
- Private SharedPreferences содержит только versioned IV+ciphertext, Base64 используется **только для бинарной упаковки шифротекста**, не как способ защиты секрета. Email и пароль шифруются вместе. Room/кэш/Android Intent/logs не затронуты. Android Backup/transfer остаются выключенными.
- На старте, если запись существует, локально расшифровать и заполнить поля. При отсутствии или повреждении ключа не использовать незащищённый fallback и не стирать каталог Room; пользователь может ввести данные вручную и сохранить заново. Нельзя показывать exception text пользователю.
- Поскольку устройство может быть разблокировано, это **шифрование при хранении**, не биометрическая защита и не защита от вредоносного ПО на скомпрометированном устройстве. Удаление приложения удалит ключ; перенос в другое приложение или на другое устройство не предусмотрен.
- Пароль Cloud.Mail.ru нельзя использовать как пароль подписи APK. Никаких изменений URL, сетевых запросов, состояния очереди, WebDAV, индексации или GMS.

## Альтернативы
Plaintext prefs/Room — отвергнуты; Google Play/Firebase Security — запрещены; deprecated security-crypto — не используется; сохранение автоматически без явного согласия — отвергнуто. Системный `AndroidKeyStore` + AES-GCM выбран.

## Проверка
CI компиляция/линт + статический контракт, Android device smoke: свежий вход вручную → Save → перезапуск → restore + playback → Forget → перезапуск → снова ручной вход при сохранённой Room. Не публиковать приватные данные/скриншоты в публичном репозитории. Не мержить до принятия Huawei.
