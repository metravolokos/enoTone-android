# ADR-0012: Без маркеров GMS в debug APK

Дата: 2026-11-08 | Статус: предложено к проверке | Автор: ChatGPT

## Контекст
CI run 42462612361 (HEAD bcfb3e9aad8a7191f97f3a8e352859c2333573b9): build, unit, lint и dependency resolution успешны; scanner обнаружил строку com.google.android.gms в classes.dex. Одно лишь дерево зависимостей не гарантирует APK без optional references.

## Варианты
1. Добавить исключение/whitelist для строк в DEX — **отклонено**: нарушает требование запрета в APK и может скрыть реальную зависимость.
2. Удалить AndroidX Activity/Compose — нецелесообразно без конкретной локализации, противоречит принятому стеку.
3. Включить R8 shrinking debug, чтобы убрать неиспользуемые классы при сохранении строгой проверки всех байтов APK. Минусы: усложняется отладка и сборка дольше.

## Решение
Временно вариант 3 для теста в M0. Он **не объявлен успешным** до зелёного APK scan; если проблема останется, установить конкретное происхождение строки и скорректировать зависимости/исходники. Никаких silent exceptions.

## Проверка
CI build, unit, lint, runtime GMS dependency graph, полное сканирование APK включая DEX и binary manifest, ручной запуск на Huawei. Пересмотр при проблемах с R8.
