# ADR-0002: minSdk 26, targetSdk 36 и запрет GMS

Дата: 2026-11-08 | Статус: принято для M0 | Автор: ChatGPT

## Контекст и варианты
min 26 сохраняет поддержку Android 8+, target 36 стабильный целевой уровень по требованиям 2026. Альтернатива target 37 потребует проверки новых ограничений. Запрещены Play Services/Firebase/Play; AndroidX и Google Maven сами по себе не запрещены. Проверять dependency graph + APK. Источник: https://developer.android.com/google/play/requirements/target-sdk

## Решение и последствия
Считать выбранные решения границей соответствующего этапа; не изображать запланированное работающим в M0. Новые зависимости и отклонения фиксировать новым ADR.

## Проверка / пересмотр
Проверка исходников, CI, mock и реального Huawei в соответствующем этапе; при расхождении — новый ADR с измерениями.
