# ADR-0079: Ресурсы дизайна Android v2 в приложении (шаг D1)

Дата: 2026-11-12 | Статус: предложено (PR `feature/m6-0-design-resources`) | Автор: Claude (по решению владельца) | Связано: ADR-0073, ADR-0074, [DESIGN_PLAN](../DESIGN_PLAN.md)

## Контекст

Владелец утвердил целевой дизайн Android v2 (2026-11-12): иконка приложения v2.0, собственный набор значков UI Icons v1, Wordmark v2.0, 12 поз мультяшного Бандита, палитра «Графит»/«Фарфор», шрифты Onest и Unbounded. Источник — репозиторий `enotone-design` (`main` `ea2931cc3dad02811804f346bb341f06fb7ab95a`). Экраны переводить нельзя до M6-0/5 (визуал заморожен ADR-0073/0074). В манифесте нет `android:icon` (аудит 2026-11-11, «Низкие»).

## Рассмотренные варианты

1. **Подключить ресурсы сейчас, отдельным PR, без изменения экранов (выбрано).** Плюсы: при переносе экранов (D2–D6) всё уже на месте и проверено CI/lint/GMS-gate; иконку можно проверить на Huawei заранее; PR без логики — минимальный риск. Минусы: до D2 ресурсы не используются кодом — нужен `tools:keep` от `shrinkResources`/lint; +≈2 МБ к APK раньше, чем появится польза.
2. **Подключать ресурсы вместе с экранами на шагах D2–D6.** Плюсы: ни одного неиспользуемого ресурса. Минусы: большие смешанные PR (ресурсы + вёрстка), иконку не проверить до конца M6-0, повышенный риск при переносе.
3. **Подключить `enotone-design` как git submodule.** Плюсы: автоматическая синхронизация. Минусы: усложняет CI и Gradle, в приложение может попасть непроверенный ресурс; обновления редкие. Отклонено.

## Решение

- Иконка: `mipmap-anydpi-v26/ic_launcher{,_round}.xml` (adaptive: прозрачный foreground + `ic_launcher_background` = `#1B1A19`), legacy PNG 48 dp; `android:icon`/`android:roundIcon` в манифесте. Monochrome — не добавляется (отложено владельцем).
- `drawable/ic_eno_*.xml` — 19 VectorDrawable UI Icons v1 без правок; существующие `ic_action_*`, `ic_nav_*`, `ic_music_*` не тронуты.
- `drawable/enotone_wordmark.xml` + `values{,-night}/wordmark_colors.xml`.
- `drawable-nodpi/bandit_*.webp` — 12 поз: высота 720 px, WebP (цвет — качество 92, альфа без потерь; глазом не отличить от lossless при 2× увеличении, размер ≈ в 4 раза меньше: 0,9 МБ вместо 3,3 МБ). Скрипт `tools/convert_bandit.py`.
- `values{,-night}/eno_colors.xml` — только токены `tokens/colors.json` v1.3 (`eno_background`, `eno_surface`, `eno_surface2`, `eno_text`, `eno_text_secondary`, `eno_accent`, `eno_accent_text`). Дополнительные токены (линии, «на акценте», вторичный акцент) — на шаге D2 после согласования.
- `font/onest.ttf`, `font/unbounded.ttf` — вариативные TTF из `google/fonts` (SIL OFL 1.1), лицензии — `docs/licenses/`. Не downloadable fonts.
- `raw/keep_design_v2.xml` с `tools:keep`.
- Kotlin-код, экраны, Room, `:playback`, сеть, CI — без изменений.

## Последствия

- APK растёт примерно на 2,3 МБ (шрифты ≈ 0,96 МБ, Бандит ≈ 0,88 МБ, иконка ≈ 0,5 МБ).
- Видимое изменение — только иконка приложения.
- На шаге D2 `tools:keep` убирается для ресурсов, которые начали использоваться.

## Как проверить / когда пересмотреть

CI точного HEAD (сборка, lint, GMS-gate). Huawei: иконка на рабочем столе (маска лаунчера не режет уши, под фигурой нет пустоты), в «Недавних» и уведомлении; экраны как раньше. Пересмотреть при новой версии ресурсов в `enotone-design`.
