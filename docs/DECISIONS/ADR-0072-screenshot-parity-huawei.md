# ADR-0072 — эталонные скриншоты Apple Music Android vs enoTone Huawei

**Дата:** 2026-11-11. **Статус:** указание владельца — повторять приложенные Android-скриншоты максимально точно; реализация в PR #77 — кандидат до подписанного APK и визуальной Huawei-проверки.

## Исходный материал

Пользователь предоставил 20 снимков 946×2048 px с двумя приложениями — `com.apple.android.music` и `app.enotone.android.preview` — на одном Huawei, включая:
- Now Playing (Aerosmith / 4 Non Blondes, pause/play), мини-плеер, системные полосы;
- Songs / Albums / Artists списки, поиск, нижняя навигация;
- открытый альбом Big Ones и Bigger, Better, Faster, More!.

Apple Music Android — **главный визуальный эталон**, пользователь разрешил создавать **отключённые заглушки** для отсутствующих функций. Это меняет прежнее ограничение ADR-0071, запрещавшее даже нарисовать иконки будущих функций. Изображения Apple Music не копировать в публичные ассеты проекта. Существующие обложки в enoTone берутся из медиатеки пользователя.

## Сравнение и исправления

| Зона | Расхождение #322 | Правило кандидата |
|---|---|---|
| Верх списка | нет постоянного поиска, Title слишком высоко, другое расположение toolbar | круглый Back, круглые Filter/More заглушки, крупный заголовок с реальным поиском 52dp |
| Songs/Albums actions | русское «Воспроизвести альбом» переносится на 2–3 строки | две капсулы по 48dp с кратким «Воспроизвести»/«Перемешать», всегда по одной строке |
| Album list | нет постоянного поиска, начало сетки выше эталона | фиксированные 2 колонки, зазор 16dp, квадратные cover и однострочные подписи |
| Artist list | нет поиска; фото неизвестны | реальные имена и круги с начальными буквами (не подменять чужими фото), чёткие строки/разделители |
| Album detail | чёрный фон, серые переносимые кнопки, метаданные расползаются | цветная полноэкранная подложка из уже загруженной обложки, white text, cover 242dp, Shuffle circle + Play white pill + Add disabled |
| Now Playing | цвета не соответствуют, Material3 slider массивный, блоки смещены | палитра по цветным областям cover, 3 радиальные заливки, компактная дорожка 4dp, трек/исполнитель с кнопками справа, место для quality-бейджа, нижние 3 иконки |
| Состояние PAUSED | другая геометрия плеера | центральная обложка уменьшается до 0.84 **без смещения остальных элементов** |
| Два острова | слишком непрозрачные/плоские | разные капсулы mini/navbar со скруглением 26/34dp, полупрозрачный нейтральный фон и граница |
| Системные панели | контраст и фон могут расходиться | edge-to-edge, белые системные знаки над Now Playing и цветным альбомом |

## Заглушки и реальные действия

- **Работают:** локальный поиск в разделах, Play/Shuffle, Media3 previous/play/next, seek (тонкий touch-accessible ползунок), повтор/перемешивание в меню, системная громкость в меню, локальные обложки/теги.
- **Заглушки (визуальные, без действия):** избранное-звезда, Add в плейлист, фильтр/сортировка, общая кнопка дополнительных действий в toolbar, Lyrics, Cast и отдельный Queue sheet. Для реального текста песни/кастинга/избранного нужны отдельные функции. Строка Lossless на Now Playing пока служит только макетом: **не является измеренным кодеком** и должна быть заменена фактическим показателем позднее.
- **Не заявлено как готовое:** настоящий backdrop blur за полупрозрачными капсулами (текущий рендер только альфа/рамка/тень), анимированный переход mini → sheet, автоматическая подстановка реальных фотографий артистов. Эти пункты остаются следующими итерациями по сравнительным скриншотам.

## Неизменные части

Room v4 и существующая локальная медиатека, WebDAV, Media3 service, индексатор, постоянные изображения до 1200px (filesDir), пакет `app.enotone.android.preview` и signing. Палитра рассчитывается **из bitmap в RAM**, без дополнительных HTTP GET и без изменения мастера обложки.

## Приёмка

Пройти exact-HEAD CI/Android/Lint и выпустить только подписанную Stable Preview. На Huawei сравнить *пары* экранов: (1) root Songs, (2) Albums, (3) Artists, (4) Album detail для цветного синего и пёстрого artwork, (5) Now Playing PLAYING/PAUSED для синих и разноцветных обложек, (6) светлую тему и обе системные полосы, (7) scroll под островами. Визуальное совпадение **не подтверждается одним только CI**.
