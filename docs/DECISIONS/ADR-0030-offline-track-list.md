# ADR-0030 — первый экран треков из Room, до полного индексирования тегов

Дата: 2026-11-08. Статус: предложено (Draft PR M2).

## Контекст

В Huawei Preview #67 два последовательных ручных пилота успешно обработали 10 + 20 файлов: 30 завершённых, ноль ошибок, 3560 без тегов. При этом локальная Room уже хранит перечень **всех 3590 файлов** из одного `PROPFIND Depth: 1` плоской `/AllMusic`. Принудительное сетевое извлечение тегов остальных файлов для первого UI не требуется.

## Решение

- Добавить отдельный локальный read-only экран «Треки» со списком из Room. Вход из существующей диагностики по введённому e-mail, пароль не нужен; сеть вообще не вызывается.
- Для файлов с тегом отображать title/artist/album, для файлов без тега — понятное название из `fileName` без последнего расширения. Не выдавать fallback за встроенный тег.
- Фильтровать по хешу указанного аккаунта и `missingScans == 0`, сортировать детерминированно по названию с резервом по id, искать локально по заголовку, артисту и альбому.
- Чтение Room выполнять с `Dispatchers.IO`; список рендерить через Compose `LazyColumn`. Один локальный snapshot из 3590 объектов допустим в M2 preview; загрузки файлов/обложек нет.
- Названия и теги показываются только в пользовательском интерфейсе устройства. Не писать личные пути, имена и теги в Git, логи, telemetry или диагностические сообщения.

## Альтернативы

1. Подождать индексации всех 3590 файлов — отклонено: увеличивает сетевую стоимость и блокирует полезный UI.
2. Каждый раз читать PROPFIND при входе — отклонено: уже есть Room snapshot; приложение должно открываться без сети.
3. Сразу строить FTS/группировку по альбомам — отложено до отдельных PR с миграцией БД и проверкой качества тегов.

## Проверка и границы

JVM unit test с 3590 синтетическими файлами, выбором одного аккаунта, исключением `missingScans`, fallback и поиском. CI Android/JUnit/lint/GMS-free/Preview APK на точном HEAD, затем локальная ручная проверка на Huawei.

Это только read-only экран, **не** проигрывание и не доказательство готовности полноценных Album/Artist/FTS. Ручные пилоты ограничены прежними бюджетами. Новая Preview имеет отдельную Room и потребует одноразового импорта списка (без скачивания аудио).
