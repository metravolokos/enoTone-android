# ADR-0070 — Huawei #314: насыщенный фон и единые системные области

Дата: 2026-11-11. Статус: решение пользователя по аппаратным скриншотам; исправления кандидат до exact-HEAD CI и новой проверки на Huawei. Дополняет ADR-0069.

## Наблюдения

- Сейчас темная палитра обложки сверху смешивалась с черным на 59%, снизу на 88%; на Huawei вместо цветного фона выглядела практически черной. В сравнении с приложенными образцами Apple Music цвет не передавался.
- Отдельные видимые подписи «Пауза» и «Буферизация» в Compose Column изменяли положение seek и транспортных кнопок.
- Серая системная строка состояния и белая жестовая панель не продолжали фон приложения.
- Тень на обложке недостаточно заметна.

## Исправление-кандидат

- Три плавно анимируемые градиентные остановки из уже имеющихся цветов обложки: темный верх с 18% смешивания с черным, середина с 14%, низ с 28%. Светлый вариант мягко смешивается с белым, без затемнения к черному. Значения требуют оценки на Huawei, не окончательно приняты.
- PAUSED / BUFFERING и диагностические состояния сохраняются в Media3 и TalkBack semantics (stateDescription), но не добавляют строки текста в видимый UI. Вторичная строка одна и постоянная: исполнитель, либо альбом при отсутствии исполнителя.
- Android Activity включает enableEdgeToEdge, прозрачные status/navigation bars и правильные значки по выбранной теме. На Android 10+ отключен лишний навигационный contrast scrim. Home / Library / Settings отступают по system bars, а Now Playing рисует фон за обеими системными областями при безопасных отступах контента.
- Вокруг обложки усилены ambient/spot тень и мягкий радиальный слой глубины; визуальная анимация уменьшения в PAUSED остается, но не изменяет высоту компоновки.

## Не изменяется

Room v4, список 3590 файлов, WebDAV и индексатор, Media3 и очередь, мастер-обложки до 1200 px в filesDir, подпись Stable Preview, приложение и packageId. Палитра локальная: дополнительных GET не возникает.

## Верификация

Сначала exact-HEAD CI, затем подписанный APK поверх текущей Stable Preview. Проверить светлую/темную тему и контраст системных значков; разные цветные обложки; заметность градиента и тени; неизменное положение кнопок при PAUSED/BUFFERING/PLAYING; жестовую полоску, длинные кириллические названия и работу воспроизведения. Аппаратная приемка остается открытой.
