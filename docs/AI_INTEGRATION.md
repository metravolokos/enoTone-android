# AI — только будущее

Планируемые AiAgentGateway и AiToolRegistry, совместимый с OpenAI API HTTPS endpoint; выключено по умолчанию. Передавать можно лишь метаданные, не аудио, не облачные пути и не credentials. Изменения подтверждаются пользователем. На M0 ни ИИ-функций, ни сетевых вызовов к ИИ нет.
