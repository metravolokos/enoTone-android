# Playback queue — контракт будущего

Реальный порядок shuffle = Fisher–Yates, фиксируется до следующей перестройки. При включении shuffle текущий трек остаётся текущим; при выключении восстановить исходный порядок. Repeat off/all/one. Preload текущего и следующего реальных элементов очереди. Pause не прекращает скачивание. M0: **не реализовано**.
