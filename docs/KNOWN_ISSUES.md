# Известные проблемы и ограничения

- M1: реальный WebDAV успешно перечисляет 3590 треков, но пока **не сохраняет** их в локальную базу через UI. В новом PR только модели Room и слой SnapshotStore.
- Нет удаления треков из БД (консервативная политика до полноценной синхронизации), чтения тегов, FTS, UI медиатеки, проигрывания.
- WebDAV XML имеет временный лимит 16 МиБ; расширить только вместе с потоковой обработкой.
- В публичные отчёты не экспортировать имена файлов, encodedPath, ETag, email, пароли. Android Backup и перенос приватных данных исключены.
- Room versioned schema JSON пока не зафиксирована: перед release нужно внести экспортируемую v1 и миграционные тесты.
- Лицензия собственных исходников для F-Droid и Gradle Wrapper — открыты.
