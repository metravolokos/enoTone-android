## Воспроизведение

| Проблема | Последствие | План |
|---|---|---|
| Восстановление требует добровольно сохранённого входа в LocalCredentialVault | При RAM-only входе или удалении сохранённого входа очередь намеренно не восстанавливается; это не дефект | Ограничение ADR-0075 |
| Временный аудиокэш удаляется при старте службы; нет закрепления current/next, только LRU 512 МиБ | Повторный трафик после перезапуска | Позже, отдельный ADR |
| `EnoTonePlaybackService` `exported="false"`, нет `MediaLibraryService` | Внешние MediaController / Android Auto могут не подключиться (не проверено) | Позже |

| Bluetooth MediaSession после смерти процесса не умеет onPlaybackResumption | Автоматическое возобновление гарнитурой без открытия приложения недоступно | Отдельный PR |

## Данные и сеть

| Проблема | Последствие | План |
|---|---|---|
| Нет колонки длительности трека | Нельзя показать длительность до воспроизведения | M6-0/6 |
| Нет таблиц плейлистов | ТЗ 6.7 не выполнено | M6-0/6 |
| ID трека = SHA-256(source + encodedPath) без канонизации кодирования; переименование = новый трек | Потеря будущих плейлистов при rename | M6-0/6 |
| Поиск и группировка в памяти, нет FTS/Paging, сортировка без `Collator` и ё/е | Не масштабируется на десятки тысяч треков | M6-0/7 |
| Три HTTP-стека (Ktor CIO, HttpURLConnection, HttpsURLConnection), нет общего backoff с джиттером и `NetworkCallback` | Дублирование логики; системный прокси/VPN для Ktor CIO не проверен | Отдельный ADR после M6-0 |
| Корневой путь жёстко `/AllMusic` | Нельзя выбрать другую папку | Позже |
| Теги только MP3/FLAC | ogg/opus/m4a/wav без тегов | Позже |

## Не реализовано из ТЗ (не дефекты, а объём)

Экспорт диагностического отчёта и кольцевой буфер логов; `ACTION_VIEW/SEND`; SAF-источник; экран очереди с редактированием; настройки и интерфейсы ИИ; UI плейлистов; ландшафт/планшеты (ориентация зафиксирована portrait).

## Ограничения, принятые владельцем

Плоская `/AllMusic` без рекурсии; нет Wi-Fi-only; обложки — постоянное хранилище без автоматической очистки. Не являются дефектами.
