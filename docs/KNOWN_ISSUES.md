# Известные проблемы и ограничения

- **Blocker M0:** в CI run 42462612361 GMS scanner выявил строку `com.google.android.gms` в classes.dex, хотя runtime dependency graph её не содержал. R8 debug shrink добавлен для повторного теста. При сохранении маркера требуется поиск источника и устранение, а не исключение из scanner.
- CI до полной проверки GMS не считается зелёным, APK не распространять.
- В репозитории пока нет настоящих Gradle wrapper JAR/скриптов, CI пользуется setup-gradle 8.13.
- Диагностика M0 показывает только whitelisted HTTP статусы/ETag presence/Range, не парсит содержимое 207 multistatus. Реальное облако не проверено.
- Экспорт отчёта в файл/clipboard и дальнейшее защищённое хранение credentials отложены. Сейчас данные вводятся только на время сеанса.
- Отказ от GMS включает не только зависимости, но и конечный APK; строгость проверки сохраняется.
