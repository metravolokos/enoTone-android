# Известные проблемы и ограничения

- M1 не завершён: пока нет Room-медиатеки, тегов, автоматической синхронизации, UI списков и playback.
- В WebDAV клиенте временный лимит 16 МиБ на XML. Большая медиатека может его превысить; нужен потоковый вариант с батчевой записью Room.
- PROPFIND Depth: infinity на Huawei завершился тайм-аутом за 15 секунд; M1 использует только Depth:1.
- Реальные имена файлов, пути, ETag и credentials нельзя публиковать в логах/отчётах. Новую кнопку проверить по числовому отчёту на Huawei.
- Для F-Droid ещё требуется выбор лицензии собственного кода; Gradle Wrapper отсутствует.
- Отложены экспорт отчёта в файл/clipboard и защищённое долгосрочное хранение credentials. Сейчас они только в RAM.
- Предыдущие GMS маркеры optional TLS/Photo Picker из M0 были устранены через Ktor CIO + debug R8; строгая CI проверка APK без исключений.
