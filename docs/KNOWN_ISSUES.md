# Известные проблемы и ограничения

- Ручная проверка локальной Room записи на Huawei ещё не проведена. PR с диагностическими кнопками ожидает CI.
- В WebDAV клиенте временный предел XML 16 МиБ. При ошибке база не обновляется; для больших библиотек нужен потоковый безопасный импорт.
- SnapshotStore не удаляет отсутствующие файлы; вместо удаления есть безопасный счётчик missingScans.
- База содержит имена/пути/ETag в приватной памяти устройства; **не** облачный backup/transfer, не учётные данные. Для открытия локального каталога после перезапуска требуется вновь ввести email для идентификатора источника.
- Room schema v1 зафиксирована; нужны инструментальные тесты открытия БД и миграций перед релизом.
- Нет тегов, FTS, обложек, медиатеки с группировкой и playback.
- Лицензия собственного кода для F-Droid и Gradle Wrapper пока открыты.

- Снимки с Huawei показывают 3590 локально сохранённых аудиофайлов; автоматическая проверка открытия Room после перезапуска и аудит сетевого трафика отдельно не проводились.
- Теги пока не извлекаются из Cloud.Mail.ru. Платформенный MediaMetadataRetriever / MediaDataSource адаптер требует протестированного WebDAV Range источника, прежде чем запускать массовую индексацию.
