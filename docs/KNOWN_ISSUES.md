## Воспроизведение

| Проблема | Последствие | План |
|---|---|---|
| Первая очередь после запуска службы может играть без временного кэша: он готовится в фоне и подхватывается для следующей очереди (ADR-0094) | Первый трек после перезапуска службы загружается по сети, предзагрузка следующего начинается со второй очереди | Пересмотреть после замера на Huawei, если станет заметно: греть кэш при входе в приложение, не в `playQueue` |
| Размер и ETag фиксируются при создании очереди, ответ 416 не обрабатывается | Изменённый на сервере файл не играет до пересоздания очереди | Требует ADR сетевого слоя |
| `restoredAccount` не сбрасывается при неудачном восстановлении | Один сбой восстановления блокирует его до перезапуска процесса | Отдельный PR |
| В UI только числовой код ошибки, кнопки «Повторить» нет | Пользователь не понимает причину и не может повторить | D6 |
| Нет `NetworkCallback`: смена Wi-Fi↔LTE во время трека даёт ошибку | Ручной повтор после переключения сети | ADR сетевого слоя |
| Временный аудиокэш удаляется при старте службы; нет закрепления current/next, только LRU 512 МиБ | Повторный трафик после перезапуска | Позже, отдельный ADR |
| `EnoTonePlaybackService` `exported="false"`, нет `MediaLibraryService` | Внешние MediaController / Android Auto могут не подключиться (не проверено) | Позже |
| Bluetooth MediaSession после смерти процесса не умеет onPlaybackResumption | Автоматическое возобновление гарнитурой без открытия приложения недоступно | Отдельный PR |

## Данные и сеть

| Проблема | Последствие | План |
|---|---|---|
| ID трека = SHA-256(source + encodedPath) без канонизации кодирования; переименование = новый трек | Смена имени не переносит элемент плейлиста на новый ID | Ограничение ADR-0085 |
| Отказ от FTS4 (#143, ADR-0091): индекс удалён, Room v7, поиск по готовым ключам | Аппаратное подтверждение обновления v6→v7 поверх 677 и порога ≤20 мс ещё не получено | Сборка 695; не закрывать до Huawei (SRCH-05/07) |
| Три HTTP-стека (Ktor CIO, HttpURLConnection, HttpsURLConnection), нет общего backoff с джиттером и `NetworkCallback` | Дублирование логики; системный прокси/VPN для Ktor CIO не проверен | Отдельный ADR после M6-0 |
| Корневой путь жёстко `/AllMusic` | Нельзя выбрать другую папку | Позже |
| Теги только MP3/FLAC; ID3v2.3 tag-level unsync осознанно отвергается, MPEG-2/2.5 и гибридный unsync не имеют отдельных фикстур (#182) | Другие форматы и редкие MP3/ID3-кейсы поддерживаются не полностью | Отдельное решение и тесты по [#182](https://github.com/metravolokos/enoTone-android/issues/182), без изменения текущего сетевого бюджета |
