# WebDAV Cloud.Mail.ru: гипотезы

**ГИПОТЕЗА — проверить на устройстве**: `https://webdav.cloud.mail.ru/`, полный email и отдельный пароль для внешнего приложения, путь `/AllMusic`. Возможны нестандартные PROPFIND Depth 1 / infinity, ETag, Range GET, URL-кодирование кириллицы и NFC/NFD; тесты должны различать 207, 401/403/404/429/5xx. Не считать Depth infinity и Range поддержанными без явного теста.

Диагностический отчёт содержит HTTP-коды, факт наличия ETag/Accept-Ranges, время ответа и статус теста. **Не содержит** логин, пароль, Authorization, путь к личному файлу, значения ETag, Cookie, имена треков.
