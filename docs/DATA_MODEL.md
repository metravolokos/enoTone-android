# Data model — план M1

Track (stable id, source id, normalized path, remote ETag/size/mtime, metadata); Artist, Album, Playlist, PlaylistItem. Room/FTS, экспорт схем и миграции; отсутствие/удаление файлов отмечать осторожно. В M0 схемы базы **нет**.

## Ограничение текущей медиатеки (владелец, 2026-11-08)
`/AllMusic` — плоская директория без подпапок. Для `Track` достаточно стабильного исходного пути каждого файла непосредственно в корне; не создавать древовидную модель папок как предпосылку M1. Сущности `Artist` и `Album` выводить из метаданных треков (тег `albumArtist`, `artist`, `album`), не из сегментов удалённого пути. При отсутствии тегов использовать имя файла как fallback для `title`, остальные неизвестные свойства обозначать отдельно; не придумывать альбом/исполнителя по папке.

Модель стабильных ID остаётся устойчивой к изменению тегов и ETag; ETag/размер/mtime хранить как версию удалённого файла, а не как часть первичного ключа. Детали схемы/миграций — в M1.
