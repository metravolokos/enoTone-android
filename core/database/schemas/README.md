# Room schema history

`app.enotone.database.EnoToneDatabase/1.json` is the **actual Room/KSP schema v1** exported in successful GitHub Actions run [#24](https://github.com/metravolokos/enoTone-android/actions/runs/42470949763) from commit `5e36ea409b562f6173fd516cf764130b7bee479c`.

Review and commit later exported versions before changing database structure; migrations must be explicit, never use destructive fallback. This is a schema baseline, **not** a claim that an Android device migration was tested. The Room store is not yet connected to the user-facing screen.
