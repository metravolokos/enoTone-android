# Решения по интерфейсу Android v2 — журнал

**Этот файл — источник истины по решениям интерфейса Android v2.** С 2026-11-15 журнал ведётся здесь, в `design/docs/` репозитория приложения (раньше — документ проекта claude.ai `DECISIONS_android_v2_ui.md` и репозиторий `enotone-design`, теперь архивные).

Эталон: холст «Дизайн аудиоплеера «Енот»», ряд «Android v2 — минимализм» (источник — `design/canvas/`); экспорт — `design/assets/ui-screens/android-v2/` (01–13). Значки — UI Icons v1 (`design/assets/ui-icons/v1`). Бандит — `design/assets/bandit/clean/` и `BANDIT_SET_V1.md`. Логотип — Wordmark v2.0 (`design/assets/wordmark/v2`, Android: `drawable/enotone_wordmark.xml` с цветами темы). Все решения можно пересматривать: дизайн меняется на холсте, затем строка здесь. **Более поздняя строка заменяет более раннюю там, где они расходятся.**

| Дата | Решение |
| --- | --- |
| 2026-11-12 | Нижняя панель: «Домой · Песни · Альбомы · Артисты · Авторы». «Авторы» = исполнители альбомов (заголовок экрана «Авторы альбомов»). Строки: `nav_album_artists`, `title_album_artists`. |
| 2026-11-12 | Наверху экранов нет кнопки «назад» и панелей: возврат системным жестом; «Сейчас играет» сворачивается свайпом вниз. *(Ручки и кнопки «Свернуть» нет — уточнено 2026-11-14.)* |
| 2026-11-12 | Мини-плеер: обложка+название (открывает «Сейчас играет»), ровно две кнопки — пауза/играть и «следующий»; тонкий прогресс со слоем буфера. Показывается только когда есть что играть (нет на «Медиатека пуста»). |
| 2026-11-12 | Буферизация на линейке и точка следующего трека — см. [SPEC_NOW_PLAYING_BUFFERING](SPEC_NOW_PLAYING_BUFFERING.md). |
| 2026-11-12 | Действия с песней: «⋮» в строке **и** долгое нажатие открывают один и тот же лист («Играть следующей», «В конец очереди», «Перейти к альбому», «Перейти к исполнителю»). Долгое нажатие остаётся всегда; «⋮» можно убрать позже. В Compose — `combinedClickable` с `onLongClickLabel` для TalkBack. На плитках альбомов и строках исполнителей «⋮» нет — только долгое нажатие. |
| 2026-11-12 | Экран альбома: без заголовков «Диск N». Песни идут подряд, отсортированы по (диск, номер трека); номер показывается внутри диска и начинается заново: 1-2-3-4-5-1-2-3. |
| 2026-11-12 | Экран альбома: обложка → название → исполнитель (акцент) → «год · жанр · N песен, M мин» → «Играть», «Перемешать», «⋮». Редкие действия (обновить теги) — в «⋮». Нужна длительность трека в БД (`durationMs`, аудит В4). |
| 2026-11-12 | Обложки во всех местах — с едва заметной окантовкой 1 px, чтобы белые обложки не сливались с «Фарфором». *(Обложка «Сейчас играет» — с отдельной обводкой, см. 2026-11-14.)* |
| 2026-11-12 | **Индикатор играющего трека — «звуковая волна»**: **4** вертикальных столбика, каждый плавно качается вверх-вниз со своим периодом **1,6 / 2,6 / 1,9 / 2,2 с** (разные фазы, туда-обратно, кривая ease-in-out `cubic-bezier(.45,0,.55,1)`, диапазон 30–95 % высоты). В «Песнях», у исполнителя, в «Недавно добавленных песнях» — поверх обложки строки 44 dp: лёгкое затемнение ≈ 30 %, столбики белые с мягкой тенью, ширина 2,5 dp, зазор 2,5 dp, высота до **14 dp**, выравнивание по низу с отступом 12 dp. На экране альбома — вместо номера трека, столбики цвета акцента, высота до 14 dp. Название трека — цветом акцента. **Пауза:** столбики замирают низкими (≈ 25 %), затемнение остаётся. «Убрать анимации» → неподвижные столбики средней высоты. Анимация **декоративная**: Android `Visualizer` (нужен `RECORD_AUDIO`) не использовать. В Compose — `rememberInfiniteTransition`, `graphicsLayer { scaleY }` с `transformOrigin` внизу; анимируется только видимая строка; `contentDescription` строки — «играет». |
| 2026-11-12 | **Прокрутка (вариант B):** всё содержимое экрана прокручивается как одна страница. Мини-плеер и нижняя панель закреплены; в конце списка отступ под мини-плеер. Когда крупный заголовок уходит вверх, появляется тонкая полупрозрачная полоска (фон ≈ 84 % + размытие): слева название одной строкой, справа круглые кнопки Ø 40 dp — «Перемешать» (`surface2`) и «Играть» (акцент). Повторное нажатие на активную вкладку — прокрутка в начало. *(С 2026-11-14 — только на экранах альбома и исполнителя.)* |
| 2026-11-12 | Исполнители без фото: круг с первой буквой имени (Unbounded 600), цвет — из 6 тонов палитры, детерминированно по имени. Обложку альбома вместо портрета не подставлять. |
| 2026-11-12 | «Артисты»: строка — аватар, имя, «N альбомов · M песен» (или «Песни в сборниках · M песен»). «Авторы альбомов»: «N альбомов»; первая строка — «Разные исполнители» (сборники) со значком группы. |
| 2026-11-12 | Экран исполнителя: аватар → имя → «N альбомов · M песен» → «Играть», «Перемешать», «⋮» → лента «Альбомы» (горизонтальная) → **все** песни исполнителя списком (без «Показать все»). |
| 2026-11-12 | Вход в «Настройки» — значок справа в заголовке «Домой» (в нижней панели настроек нет). |
| 2026-11-12 | **«Домой» — вариант C2:** крупный заголовок «Домой», справа значок настроек → плашка «Перемешать всё · N песен» с Бандитом в наушниках (`bandit_14_headphones_b`), выглядывающим снизу справа → лента «Недавно добавленные альбомы» → «Недавно добавленные песни» (3–5 строк, «Все» ведёт к «Песням» с сортировкой по дате). Карточки «Продолжить» нет. «Недавно играли» — позже, вместе с историей и плейлистами. |
| 2026-11-12 | **Wordmark v2.0**: своя геометрия, «one» — зеркало «eno», большая двухцветная «T», «e» с раскрытым просветом. Минимальная ширина — 120 dp. Источник — `design/tools/build_wordmark.py`, документ [WORDMARK_V2](WORDMARK_V2.md). **Показывается только в «Настройках» и «О приложении».** |
| 2026-11-12 | **Маскот — мультяшный Бандит** (контурный, плоская заливка). 3D-версия для интерфейса отклонена. |
| 2026-11-12 | **Не дублировать сущности:** указующий жест Бандита — только на иконке приложения; логотип — только в «Настройках» и «О приложении». Одна поза — одно назначение. |
| 2026-11-12 | **Бандит по экранам:** вход — сидит, «Привет! Я Бандит»; индексация — читает книгу, прогресс и «Слушать, пока читаю»; пауза без сети — уснул на книгах, «Повторить сейчас»; индексация завершена — радуется, «К музыке»; поиск без результатов — задумался стоя; нет сети — выглядывает из-за столба, «Повторить»; медиатека пуста — задумался на книгах, «Проверить подключение»; ничего не играет — отдыхает лёжа, «Перемешать всё»; «Настройки» — wordmark + версия, Бандит в кресле; «Домой» — в наушниках; подсказки и «Что нового» — с лампочкой; таймер сна (будущее) — спит на подушке. Один Бандит на экран, только в пустых состояниях/приглашениях/настройках/плашке, никогда в списках. Разметка пустых состояний: Бандит → заголовок Unbounded → 1–2 строки → одна кнопка. |
| 2026-11-12 | **Голос приложения:** сообщения пустых состояний — от лица Бандита, в первом лице, коротко и тепло. Кнопки — нейтральные глаголы. Ошибки — без технических кодов (коды — в «Диагностике»). |
| 2026-11-12 | «Настройки»: шапка (Wordmark v2.0, версия, Бандит в кресле) → группы-карточки: «Облако · Медиатека · Обновить медиатеку» / «Тема · Кэш» / «Диагностика · О приложении». |
| 2026-11-12 | **Экран эталона — Huawei Nova 15 Pro:** 1320 × 2856 px, × 3,5 → **377 × 816 dp**; область приложения 377 × 755 dp; вырез ≈ 77 × 27 dp; **радиус углов ≈ 56 dp** (`Display.getRoundedCorner()` у Huawei возвращает 0 — не полагаться). Поля 28 dp; обложка «Сейчас играет» 321 dp (от ширины); кнопки 64 / 84 / 64 dp с зазором 28; обложка альбома 240 dp; заголовки секций «Домой» 17 sp; пилюли 15,5 sp; Бандит на плашке 108 dp. Мини-плеер и панель — с отступом 12 dp от краёв. В коде размеры не захардкоживать; проверять также на 360 dp. |
| 2026-11-13 | Палитра v1.4: токены линий, текста на акценте, теней, затемнений, 6 тонов аватаров. В светлой теме розовый — только заливка; текст, значки и линии — терракотовый `#A24F3E`. Дизайн переносится полностью, со всеми эффектами. |
| 2026-11-14 | **Кнопки «Играть» и «Перемешать» — один вид во всех состояниях:** всегда полностью круглые, «Играть» — акцент и первая, «Перемешать» — `surface2`, подпись «Играть». До прокрутки — пилюли 48 dp, в полоске — круги Ø 40. **Только на «Песнях», экране альбома и исполнителя.** |
| 2026-11-14 | **Заголовок списочных вкладок** (макеты 02, 04, 06, 07): крупный заголовок, справа значок поиска, под ним счётчик. Поле поиска раскрывается по значку и не пропадает при прокрутке. |
| 2026-11-14 | **«Сейчас играет» без ручки:** экран закрывается только жестом (свайп вниз) и системным «назад»; никаких кнопок «Свернуть» и их имитаций. |
| 2026-11-14 | **На вкладках «Песни», «Альбомы», «Артисты», «Авторы» заголовок не сворачивается:** закреплён, список прокручивается под ним. При прокрутке — фон заголовка 84 % + размытие и тонкая линия снизу. Полоска варианта B — только на экранах альбома и исполнителя. |
| 2026-11-14 | **Результаты поиска называются по категории:** «Найдено 12 песен / 136 альбомов / 56 артистов / 20 авторов», «Ничего не нашлось». |
| 2026-11-14 | **«Прозрачные панели» — настройка, по умолчанию выключена:** «Настройки → Оформление → Прозрачные панели». Включено — мини-плеер и нижняя панель ≈ 72 % + размытие 24 dp; выключено — непрозрачные. ADR-0088. |
