# Спецификация: индикация буферизации на экране «Сейчас играет»

Статус: дизайн утверждён владельцем 2026-11-12, в коде не реализовано. Реализовывать **после** рефакторинга M6-0 (экран на ViewModel/StateFlow).
Эталон: холст «Дизайн аудиоплеера «Енот»», артборд «Android v2: Сейчас играет» (настройка артборда «Буферизация»); источник холста — `design/canvas/`.

## 1. Линейка воспроизведения — три слоя

| Слой | Значение | Цвет («Графит» / «Фарфор») |
| --- | --- | --- |
| дорожка | не загружено | `#3A3633` / `#CFC6BE` |
| буфер | загружено вперёд от позиции | `textSecondary` (`#B9AEA4` / `#5C544E`) с прозрачностью 38 % |
| сыграно | от 0 до позиции | `text` (`#F4ECE4` / `#211E1C`) |
| ползунок | позиция, Ø 12 dp | `text` |

- Высота линии 4 dp, скругление 2 dp; зона касания ≥ 48 dp по высоте.
- Источник: `player.bufferedPosition` / `player.duration` (Media3). Буфер ≥ позиции всегда; при полностью закэшированном треке — до конца.
- Обновление вместе с позицией (не чаще ~4 раз в секунду), только пока экран виден.
- `contentDescription` линейки: «1:26 из 3:48, загружено 64 %».

## 2. Точка следующего трека

Точка Ø 8 dp **на правом конце линии**, отдельно от неё (линия укорочена на 16 dp справа).

| Состояние | Когда | Вид |
| --- | --- | --- |
| `NONE` | следующего трека нет (конец очереди, repeat off) или предзагрузка ещё не начата | точки нет |
| `LOADING` | следующий трек загружается в кэш | цвет `textSecondary`, мигает: прозрачность 0,25 ↔ 1, период 1,1 с, ease-in-out |
| `READY` | следующий трек **полностью** в кэше | акцент (`#EBAE9F` / `#A24F3E`), горит постоянно, мягкий ореол 3 dp (акцент 22 %) |

- «Следующий» — по фактическому порядку воспроизведения: `player.nextMediaItemIndex` (учитывает shuffle и repeat all). При repeat one следующий = текущий: `READY`, когда текущий закэширован полностью.
- Готовность — по кэшу M5 (`SimpleCache`): закэшированные байты ключа следующего трека == длина файла. Сеть для проверки не трогать.
- Смена очереди, shuffle, repeat, ручной выбор трека → пересчитать состояние сразу.
- Системная настройка «Убрать анимации» (`ANIMATOR_DURATION_SCALE == 0`) → `LOADING` без мигания, прозрачность 0,6.
- `contentDescription`: «Следующий трек загружается» / «Следующий трек готов».

## 3. Модель для ViewModel (предложение)

```kotlin
data class SeekUiState(
    val positionMs: Long,
    val bufferedMs: Long,
    val durationMs: Long,
    val nextTrack: NextBufferState, // NONE, LOADING, READY
)
```

## 4. Как проверить на устройстве

1. Запустить трек без кэша → полупрозрачный слой растёт впереди ползунка, точка мигает.
2. Дождаться полной загрузки следующего → точка загорается акцентом.
3. Включить shuffle → точка пересчитывается под новый «следующий».
4. Последний трек очереди, repeat off → точки нет.
5. Выключить сеть посреди загрузки → буфер перестаёт расти, точка продолжает мигать (не «готов»).
