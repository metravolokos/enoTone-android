# AGENTS — дизайн enoTone (`design/`)

Обсуждать с владельцем по-русски; идентификаторы, имена ресурсов и файлов не переводить. Общие правила репозитория — `../AGENTS.md`; этот файл добавляет правила для `design/`.

Начинать с [README](README.md) («Если вы новый чат…»). Действует только то, что описано в [журнале Android v2](docs/DECISIONS_ANDROID_V2_UI.md), [DESIGN_DECISIONS](docs/DESIGN_DECISIONS.md) и документах, на которые они ссылаются. Остальное не утверждено.

1. **Утверждает владелец.** Любое новое или изменённое визуальное решение сначала показывается владельцу (холст, картинка), и только после его согласия попадает в `assets/`, журнал и приложение.
2. **Названия.** Продукт **enoTone** (всегда с заглавной `T`), маскот **Бандит**. Нижняя вкладка исполнителей альбомов — **«Авторы»**, заголовок экрана — **«Авторы альбомов»**.
3. **Сгенерированное не правят руками.** Меняется скрипт, затем пересборка и `tools/sync_android.py`:
   - иконка приложения v2.0 → `tools/build_app_icon.py` → `assets/icons/v2.0/` ([APP_ICON_V2](docs/APP_ICON_V2.md)); одна иконка на «Графите» `#1B1A19`, monochrome отложен;
   - значки UI Icons v1 → `tools/build_ui_icons.py` → `assets/ui-icons/v1/` ([UI_ICONS_V1](docs/UI_ICONS_V1.md)); значки категорий, воспроизведения и действий — только из этого набора;
   - Wordmark v2.0 → `tools/build_wordmark.py` → `assets/wordmark/v2/` ([WORDMARK_V2](docs/WORDMARK_V2.md)); в приложении только в «Настройках» и «О приложении»;
   - Бандит → `tools/clean_bandit.py` → `assets/bandit/clean/`, в приложение — `tools/convert_bandit.py` (через `sync_android.py --bandit`);
   - палитра → `tools/build_tokens.py` → `assets/tokens/android/res/`.
4. **Бандит.** Только мультяшный Бандит из `assets/bandit/originals/` (побайтно не менять) и `assets/bandit/masters/`. Не перерисовывать, не генерировать, не приближать; только масштаб, кадр, маска. Назначение поз — [BANDIT_SET_V1](docs/BANDIT_SET_V1.md). Указующая поза — только иконка приложения.
5. **Стиль.** «Глянцевый енот», темы «Графит» и «Фарфор», палитра — `tokens/colors.json` v1.5. В светлой теме розовый `#EBAE9F` — только заливка; текст, значки и линии — `#A24F3E`. Шрифты: Unbounded — заголовки, Onest — остальное. Новый цвет или токен состояния — только с согласия владельца.
6. **Экраны Android.** Эталон — `assets/ui-screens/android-v2/` и [UI_ANDROID_V2](docs/UI_ANDROID_V2.md); экран устройство Nova 15 Pro, 377 × 816 dp, радиус углов ≈ 56 dp. Изменение экрана: скрипт в `canvas/` → показ на холсте → после согласия PNG в `assets/ui-screens/android-v2/` и `SHA256SUMS` → строка в журнале.
7. **`design-needed`.** Нужен элемент, которого нет, — issue с меткой `design-needed`, работа над этой частью кода стоит, пока элемент не утверждён и не перенесён `sync_android.py` (порядок — [README](README.md#нужен-новый-элемент--design-needed)). Не подставлять Material-значки, «похожие» пути или заглушки.
8. **Запись изменений.** Каждое утверждённое изменение: строка с датой в [журнале Android v2](docs/DECISIONS_ANDROID_V2_UI.md) (для экранов) или [DESIGN_DECISIONS](docs/DESIGN_DECISIONS.md) + [CHANGELOG дизайна](docs/CHANGELOG.md). Оригиналы сверять по SHA-256.
9. **История.** Отменённые решения (старый коллаж Бандита из 10 сцен, иконка v1.0, Wordmark Master v1.0, SVG-кандидаты, ZIP-архивы и т. п.) удалены 2026-11-13 и есть только в архивном `metravolokos/enotone-design` до `dd0c101`; в работу не возвращать. Изменения в архивный репозиторий не вносить.
10. **Desktop** — рабочее направление в [UI_BASELINE_V1](docs/UI_BASELINE_V1.md), отложено. Раскладки Desktop и Android раздельны, токены общие.
