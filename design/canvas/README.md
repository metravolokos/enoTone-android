# Холст «Дизайн аудиоплеера «Енот»» — исходники Android v2

Здесь лежат скрипты, из которых собраны артборды ряда «Android v2 — минимализм» холста claude.ai
(артефакт `af5922c0-25a7-4899-bc92-561dfd97ed0f`), и копия файлов холста (`project/*.dc.html`, `canvas.json`).
Холст в claude.ai — рабочее место для показа владельцу; **источник истины — эти скрипты**.
Утверждённый экспорт — `../assets/ui-screens/android-v2/` (PNG + `SHA256SUMS`).

| Скрипт | Артборды |
| --- | --- |
| `gen.py` | общие функции: значки (`svg`, словарь `EXTRA`), темы, рендер PNG; «Сейчас играет» |
| `common.py` | общий CSS и разметка строк, мини-плеер, нижняя панель |
| `songs.py`, `sheet.py` | «Песни», лист действий песни |
| `album.py`, `albums.py` | экран альбома, «Альбомы» |
| `artists.py` | «Артисты», «Авторы альбомов», экран исполнителя |
| `home.py`, `home_c.py` | «Домой» (B, C, C2 — утверждён C2) |
| `scrolled.py` | состояния после прокрутки (полоска варианта B) |
| `states.py` | Бандит на экранах — пустые состояния, «Графит» и «Фарфор» |
| `wm_inline.py` | Wordmark v2.0 для вставки в HTML |
| `paths.py` | пути: `design/`, значки, Бандит, шрифты |

## Запуск

```bash
cd design/canvas
npm i @fontsource/onest @fontsource/unbounded      # шрифты для рендера (или FONTSOURCE=<путь>/@fontsource)
pip install playwright --break-system-packages      # рендер PNG через Chrome
python3 songs.py                                    # пересобрать артборд(ы) → project/*.dc.html и PNG рядом
```

PNG-выход и `_s.html` в Git не попадают (`.gitignore`). Утверждённый PNG переносится в
`../assets/ui-screens/android-v2/` с обновлением `SHA256SUMS` — только после согласия владельца.

## Как показать владельцу

Опубликовать изменённые `project/*.dc.html` в артефакт холста (Artifact `publish_files`, тот же slug,
`as` = имя файла) — владелец смотрит на телефоне. Новый вариант — отдельный артборд рядом, старый не удалять,
пока владелец не выбрал.

## Значки в черновике

Новый значок сначала рисуется в `EXTRA` (`gen.py`) и показывается на холсте. После утверждения он
переносится в `../tools/build_ui_icons.py`, собирается, и только тогда попадает в приложение через
`../tools/sync_android.py`. Значок из `EXTRA` в приложение напрямую не копируется.
