# AGENTS — правила работы над enoTone

**Перед началом любого изменения (2026-11-11): сначала читать [действующие решения](docs/CURRENT_DECISIONS.md), затем `docs/STATUS.md`, `docs/ROADMAP.md`, `docs/OPEN_QUESTIONS.md`, `docs/ARCHITECTURE.md` и последние ADR.** Исторические Draft/скриншоты/старое ТЗ не переопределяют более новые принятые решения. Истина о готовности — exact-HEAD CI, merge в `main` и отдельное сообщение владельца о Huawei с точной областью проверенного, а не текст PR.

- Разработка через `feature/<milestone>-<topic>`, Conventional Commits, небольшие PR; `main` не менять без review.
- Каждый архитектурный выбор: ADR с альтернативами, причинами, последствиями и способом проверки. Замена ранее принятого ADR только новым ADR.
- В конце сессии обновлять STATUS, CHANGELOG, KNOWN_ISSUES и, при необходимости, ADR/OPEN_QUESTIONS. Не добавлять невыполнимые заглушки.
- Документы, отчёты, архитектурные пояснения — по-русски; кодовые идентификаторы — по-английски. Комментарии объясняют причины.
- Ни GMS/Play Services/Firebase, ни телеметрии, ни сетевых вызовов вне WebDAV пользователя и явно включённого ИИ API. Только HTTPS.
- Никогда не писать credentials/путь к личной музыке в Git, логи, backup или crash. Android Keystore AES-GCM для будущего хранения, deprecated security-crypto запрещён. M0 использует только оперативную память.
- Исторический стоп-гейт M1 уже выполнен: плоская библиотека **3590/3590** FLAC/MP3 прошла массовую индексацию. **Обычный импорт/обновление — одно действие**, работающее инкрементально. Принудительную переиндексацию 3590 файлов запускать **только после отдельного подтверждения**, никогда ради простого UI smoke. Фоновый индексатор с checkpoint, Pause/Stop и без Wi-Fi-only. Контекстные меню scoped reindex ещё не добавлены.
- Перед merge проверить точный HEAD PR и все обязательные CI, включая GMS scan и APK. Нет успеха проверки — нет merge.

Ручная проверка определяется **текущим PR**. M6-B/Preview #157 уже принята и объединена (PR #30); для следующих этапов сверяться с ROADMAP/STATUS/TESTING. В Git передавать только обезличенные коды/числа, прежнюю Room не удалять.

- С 2026-11-09 Stable Preview #169 **принята** для install-over-install: Room сохраняется между APK. Новые тесты проводить на `app.enotone.android.preview`, не `.preview.rN`, не удалять данные. Начиная с Draft M0-K допускается только **добровольное** зашифрованное хранение учётных данных через Android Keystore AES-GCM; без нажатия кнопки — RAM-only. Не расширять это до автоматического сохранения и не помещать секреты в Room, backup, логи или Android Intent.

## Недопустимые регрессии в документации и коде после Huawei #301

- **Обложки: максимум 1200 px, постоянный `filesDir/enotone-artwork-v2`, без дискового LRU 64 МиБ и автоматического удаления.** Единственная мастер-картинка на фактическое содержимое, локальные экранные размеры; один выбранный artwork реального альбома в списках/мини/Now Playing. `Unknown Album` не смешивать. Старые 1320 px/`cacheDir` из ADR-0064 — **исторические**.
- Режимы изображений: `ON_DEMAND` и `AUTO_AFTER_IMPORT`, независимые от текстового тега GENRE и от временного аудиокэша. Фоновая подготовка обложек — только при выбранном режиме; инвалидация по явной переиндексации даже при неизменном ETag. Не создавать массовые image GET во время стандартного PROPFIND/индексации тегов.
- **Будущие плейлисты:** использовать ссылку на уже сохранённый альбомный мастер, **не копировать изображение повторно**. Но **не писать «плейлисты реализованы»** — пользовательских экранов и назначения обложки пока нет.
- [PR #71](https://github.com/metravolokos/enoTone-android/pull/71) + подписанная Stable Preview #301 прошли CI; владелец подтвердил **«Работает»** (базовое принятие). **Не приписывать** этому сообщению отдельный test PASS offline/нулевых GET/автообхода/ручной очистки. Точный список открытых тестов — [TESTING](docs/TESTING.md).
- При правках функционала или документации согласовывать ADR, README, ROADMAP, STATUS, TESTING, CHANGELOG, KNOWN_ISSUES и CURRENT_DECISIONS; историю не удалять, а помечать заменённое решение и ссылаться на действующее.
